WHAT'S NEW
================================================================================

1. FORMULA ENGINE (1,116 LOC)
   - AST-based formula parser with 15+ operators and mathematical functions
   - Newton-Raphson solver for constraint solving
   - Variable substitution with proper scoping
   - Complete test coverage (50+ unit tests)
   - Performance: <1ms for average expressions

2. REACT FORMULA EDITOR (520 LOC)
   - Interactive formula editing component
   - Real-time syntax highlighting and validation
   - Dark/light mode support
   - localStorage draft persistence
   - Mobile-responsive design
   - Keyboard shortcuts and autocomplete

3. OCCT INTEGRATION (2,260 LOC)
   - STEP/IGES/DXF CAD file import
   - Parametric dimension auto-extraction (±0.1mm accuracy)
   - Geometry caching with 100MB LRU cache
   - Batch processing support
   - Multi-format geometry handling

4. SMART TEMPLATES (850 LOC)
   - 3 production-ready bend templates
   - 92% auto-matching accuracy
   - Real-time recommendation engine
   - Confidence scoring (0-100%)
   - Parameter validation and conflict detection

5. SEARCH & FILTERS (3,007 LOC)
   - Full-text search with BM25 ranking
   - Fuzzy matching (Levenshtein distance)
   - 9 searchable fields
   - Sub-500ms query performance
   - Advanced filter composition

6. GROWTHBOOK ANALYTICS (1,050 LOC)
   - 50+ event types across 7 categories
   - A/B testing framework with hash assignment
   - Feature flag system with 5-min TTL cache
   - Analytics dashboard with 5 components
   - Real-time event streaming

================================================================================

  - Template libraries are preserved
  - Custom settings are maintained

Manual Steps:
  1. Back up your current v7.x projects

DATA MIGRATION
================================================================================
No data loss expected. All user data, projects, and settings are preserved
during upgrade. However, we recommend:
  - Backing up projects before upgrade
  - Testing with non-critical projects first
  - Reviewing formula syntax in critical designs

BREAKING CHANGES
================================================================================
1. Formula API Changes:
   - Deprecated LegacyFormulaParser removed
   - Use new FormulaEngine class for parsing

2. SmartTemplate API:
   - match() method now returns TemplateMatch object instead of bool
   - Access confidence via match.confidence
   - Update any custom template integrations

3. OCCT Processor:
   - OCCTProcessor now requires explicit cache initialization
   - Changed importFromFile() to importSTEP/importIGES/importDXF
   - Updated error handling with custom exceptions

These changes provide better type safety and cleaner APIs. Migration guide
available at: https://docs.bendcore.io/v8.0/migration

KNOWN ISSUES & LIMITATIONS
================================================================================
Known Issues:
  - DXF import limited to AutoCAD 2018 format and earlier
  - Formula solver limited to 100 iterations (adjustable in config)
  - Initial geometry caching may take time on first project load
  - Some special characters not supported in project names

Limitations:
  - Windows x64 only (Linux/macOS support planned for v8.1)
  - OCCT geometry cache requires contiguous memory
  - A/B testing limited to 2 variants per experiment
  - Search index limited to 10,000 items (configurable)

Workarounds:
  - Convert DXF files using AutoCAD 2019+ before import
  - Increase cache size in config for large assemblies
  - Use simpler project names with ASCII characters only
  - Reduce search corpus size for better performance

ABOUT BENDCORE
================================================================================
BendCore is a professional CAD system designed specifically for tube and pipe
bending design, simulation, and manufacturing. It combines parametric design
capabilities with advanced manufacturing constraints for optimal results.

Features for CAD Users:
  - Parametric design with formula engine
  - Template libraries for quick design
  - Advanced visualization and rendering
  - Multi-step assembly management
  - Real-time constraint solver

Features for Manufacturers:
  - DXF/STEP export for CNC programming
  - Bending toolpath optimization
  - Dimension and tolerance management
  - Material library with properties
  - Design-to-manufacturing workflow
