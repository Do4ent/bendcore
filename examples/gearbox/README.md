# Редуктор цилиндрический РЦ-80 — изделие уровня v1.0, спроектированное в bendcore

Попытка пройти критерий готовности v1.0 (`docs/ROADMAP_GENERAL_CAD.md`) силами bendcore без
человека: одноступенчатый цилиндрический редуктор (m = 2, z1 = 20, z2 = 60, u = 3, aw = 80 мм,
масса модели 20,1 кг) — детали, сборка, рабочие и сборочный чертежи, спецификация ГОСТ 2.106.
Всё строится программой (`gearbox_*.cpp`) через публичные API документа детали, документа сборки,
библиотеки крепежа и документа чертежа; ни один файл не нарисован вручную.

**Это не выпущенная документация.** Чертежи не прошли нормоконтроль, данные стандартов не сверены
(раздел «Что должен проверить человек»), часть изображений условна (раздел «Чего не хватило»).

Сопряжения: корпус зафиксирован; прокладка, крышка корпуса, 4 крышки подшипников — жёсткая связь
с корпусом; подшипники — соосность наружного кольца с расточкой + совпадение торца наружного кольца
с пояском крышки; валы — соосность с отверстием правого подшипника + заплечик к торцу внутреннего кольца; зацепление — передаточное сопряжение валов u = 60/20 = 3
(внешнее: вращение в разные стороны); колесо, втулка, шпонки — жёсткая связь с валом;
штифты, пробки и прокладки пробок — соосность + торец; крепёж — `insertFastenerStacks` (болты
крышек — в резьбовые отверстия корпуса, болты фланца — пакет «крышка + прокладка + корпус» с
гайкой). Решение: невязка < 1e-14, **59 степеней свободы** = 1 (валы связаны зацеплением) + 58 поворотов
осесимметричных деталей вокруг своих осей (подшипники, крепёж, штифты, пробки, прокладки пробок); избыточных
и противоречивых сопряжений нет.

**Правило пересечений.** Пересечений нет, кроме резьбовых соединений: резьба условная, стержень
болта М6 (⌀6) и пробки М16×1,5 (⌀16) стоит в отверстии диаметра сверла D − P (5 и 14,5). Такое
пересечение допускается, если объём не больше кольца π/4·(d² − (D − P)²) на длине захода (для болта
— выступ стержня за крышку 10,4 мм, для пробки — длина стержня 14 мм). Посадки с натягом (подшипник
на валу, колесо на валу) моделируются номинальными размерами — касание, а не пересечение;
зубья шестерни и колеса (боковой зазор нулевой, фаза зацепления задана поворотом венца шестерни)
касаются, не пересекаясь.

## Как пересобрать

```bash
cmake -S . -B build-occt -G Ninja -DBENDCORE_WITH_OCCT=ON -DBENDCORE_OCCT_DIR=<occt>
bash examples/gearbox/regenerate.sh build-occt      # обновить файлы этого каталога
build-occt/gearbox_generate <каталог>               # полный комплект: + PDF, DXF на лист, STEP деталей
ctest --test-dir build-occt -R e2e_product_gearbox --output-on-failure   # ≈ 40 с
```

Генератор воспроизводим: тот же код даёт те же документы (детали строятся из выражений
переменных; положения вычисляются из размеров).

## Что проверено автоматически (`tests/e2e-product/test_gearbox.cpp`)

- **Состав**: 13 деталей, 5 типоразмеров подшипников и шпонок из каталогов, 6 типоразмеров крепежа, 72 вхождения,
  количества по BOM против конструкции.
- **Массы**: объёмы втулки, прокладок, пробки — против формул из размеров (≤ 1e-9); подшипников
  (кольца по теореме Паппа — Гульдена, шарики) и шпонок с фасками s — против формул из размеров
  таблиц ГОСТ 8338 и ГОСТ 23360 (≤ 1e-7); зубчатые венцы колеса и вала-шестерни — объём, снятый
  нарезанием, против (π·da²/4 − A)·b + 2V_ф, A — площадь торцового профиля численным интегралом
  по точкам формул эвольвенты и переходной кривой, V_ф — объём фаски 1 × 45° на торце (интеграл
  по формуле эвольвенты) (≤ 3e-6); масса изделия по BOM = Σ V·ρ.
- **Пересечения**: только 18 резьбовых пар (16 болтов, 2 пробки), каждая не больше предельного
  кольца; зубья шестерни и колеса касаются.
- **Степени свободы**: 59, невязка < 1e-9; поворот вала-шестерни на 30° и вала с колесом на −10°
  — допустимое движение (решатель ничего не сдвигает); поворот зафиксированного вала-шестерни на φ
  (30°, −45°) поворачивает колесо на −φ/3, шпонки и втулка — вместе с ним.
- **Технические требования** листа корпуса: каждая строка (по линиям шрифта ГОСТ 2.304) — в поле
  185 мм над основной надписью, не ближе 1 мм к рамке.
- **Позиции = спецификация**: каждая из 24 составных частей — ровно одна позиция с номером из
  спецификации; разделы и порядок ГОСТ 2.106.
- **Ассоциативность**: все 50 размеров, 13 знаков шероховатости, 9 рамок допусков, базы и размеры
  резьбы привязаны к элементам модели; длина выходного конца вала 40 → 50 даёт в чертеже вала
  «L: 172 → 182», «Lend: 40 → 50», висячих нет.
- **Файлы открываются обратно**: документы деталей (тот же объём), сборка (источники загружены,
  сопряжения Kept, 59 степеней свободы, те же положения), чертежи (обновление по файлам — без
  изменений модели, без висячих, те же значения), спецификация, STEP сборки (72 детали) и деталей
  (объём корпуса ≤ 1e-6), DXF каждого листа, PDF (`pdfinfo` — 9 страниц, `pdftotext` — обозначения
  и наименования); закоммиченный комплект открывается и решается так же.

## Что должен проверить человек

- **Нормоконтроль** всех 9 листов по ЕСКД (ожидаемые замечания — ниже и `docs/V1_READINESS.md`,
  фаза 4): компоновка размеров (автокомпоновки нет — размеры могут налезать друг на друга),
  выноски позиций пересекаются; таблицы параметров венца ГОСТ 2.403 и изображение ГОСТ 2.402
  сделаны по памяти о стандартах (`docs/STANDARDS_VERIFICATION.md`).
- **Сверка стандартов** (`docs/STANDARDS_VERIFICATION.md`): каталог подшипников ГОСТ 8338
  (205: 25×52×15, 206: 30×62×16, r) и таблица шпонок ГОСТ 23360 (b×h, t1, t2, s) записаны по
  памяти — **требуют сверки**; внутренняя геометрия подшипников (шарики, желоба) условна;
  крепёж — таблицы `bendcore_fasteners`; поля допусков ISO 286.
- **Конструкция**: расчёт зацепления на прочность, валов, подшипников не выполнялся (геометрия
  зацепления — по ГОСТ 16532, x = 0, боковой зазор нулевой — допуски на толщину зуба не заданы) (размеры назначены
  конструктивно); посадки, допуски формы и шероховатости — типовые, не обоснованы расчётом
  размерных цепей; уплотнения — щелевые (манжет нет).
- **Изготовление**: чертежи не передавались на производство; STEP/DXF/PDF не открывались в
  сторонних CAD.
