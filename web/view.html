bendcore: просмотр трубы

Вставьте CSV или JSON (формат — README, раздел «Импорт»), затем нажмите «Показать». Ось трубы строится ядром (ломаная из точек оси); порты — стрелки по направлению наружу.

Если указан адрес сервиса тела трубы (README, раздел «Сервис тела трубы»), страница дополнительно показывает тело (сетку) и концевые порты. Без сервиса показывается только ось.

Порты, добавленные вручную, сохраняются до следующего «Показать».
