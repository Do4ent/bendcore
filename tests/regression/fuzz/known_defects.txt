# История: с OCCT 8.0.1, собранным с No_Exception (C++17), — 229 падений в каждой конфигурации
# (brep_binary 103, brep_text 69, step 47, assembly_json 10). После перехода на OCCT с проверками
# в Release и C++20 (OCCT_RELEASE_CHECKS=1, OCCT_CXX_STANDARD=C++20, docs/kernel/OCCT_BUILD.md,
# раздел 6), защиты от аппаратных сбоев и предварительной проверки STEP в ядре

#   (~2^28). BinTools_Curve2dSet (operator>> для Geom2d_BSplineCurve) выделяет
#   NCollection_Array1<gp_Pnt2d>(1, nbpoles) по числу из файла до чтения полюсов. Без ASan память

#   превышает hard_rss_limit_mb=4096 и завершает процесс. Исправимо только в OCCT (проверка числа
