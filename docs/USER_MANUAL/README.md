## Key Features Overview

### Parametric Design
- Fully parametric tube bend design
- Constraint-based geometry
- Associative modifications

### Manufacturing Integration
- Automatic NC program generation
- Template-based manufacturing
- Material and tooling libraries

### Analysis & Simulation
- Integrated FEA solver
- Stress and strain analysis
- Optimization engine

### Collaboration
- Real-time multi-user editing
- Version control integration
- Design review tools

### File Format Support
- STEP (ISO 10303-21)
- IGES
- SAT (Parasolid)
- DWG
- BendCore native format

## System Requirements

### Minimum
- **OS:** Windows 10/11, macOS 11+, Linux (Ubuntu 20.04+)
- **CPU:** Intel i5 / AMD Ryzen 5 or equivalent
- **RAM:** 8 GB
- **GPU:** Integrated graphics
- **Storage:** 2 GB free space

### Recommended
- **CPU:** Intel i7 / AMD Ryzen 7 or equivalent
- **RAM:** 16 GB
- **GPU:** Dedicated NVIDIA/AMD GPU with 4GB VRAM
- **Display:** 4K capable, 27+ inches
- **Storage:** SSD with 5 GB free space

## Conventions Used in This Manual

### Notation
- **Menu paths:** Use ">" to indicate menu hierarchy (e.g., "File > New > Design")
- **Buttons/Labels:** Appear in **bold** (e.g., "Click the **OK** button")
- **Keys:** Appear in `code` format (e.g., `Ctrl+S`)
- **Input fields:** Appear in `code` format (e.g., "Enter `25.4` in the **Diameter** field")

### Icons
- 📘 **Note:** Additional information
- ⚠️ **Warning:** Important cautions
- 💡 **Tip:** Helpful hints and best practices
- 🎯 **Goal:** Objective of a section
- ✅ **Task:** Action steps to follow
