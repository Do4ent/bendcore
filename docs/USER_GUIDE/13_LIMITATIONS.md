# 13. Известные ограничения

Перечень собран по разделам «Ограничения» документов модулей и по коду интерфейса.

## 13.1. Данные стандартов (⚠ требуют сверки)

Записаны без доступа к официальным изданиям; тесты сверяют геометрию с этими же таблицами
и ошибку в таблице не поймают (`docs/STANDARDS_VERIFICATION.md`):

| Что | Стандарт |
|---|---|
| Размеры граф основной надписи форм 1 и 2а | ГОСТ 2.104 |
| Стрелки и буквы обозначений разрезов | ГОСТ 2.305 |
| Размеры болтов, винтов, гаек, шайб, штифтов | ГОСТ 7798, 11738, 5915, 11371, 6402, 3128; ISO 4014, 4017, 4762, 4032, 7089, 2338 |
| Таблица IT, основные отклонения | ISO 286-1/-2, ГОСТ 25346–25347 |
| Запись нулевого отклонения, стрелки размеров | ГОСТ 2.307 |
| Знаки шероховатости, рамки допусков, базы | ГОСТ 2.309, 2.308 |
| Графы спецификации | ГОСТ 2.106, 2.104 |
| Свойства встроенных материалов | EN 1993, EN 1999, ГОСТ 1050 и др. |

## 13.2. Деталь и эскиз

- Кинематика (по эскизу и по ребру модели), по сечениям, ребро жёсткости, резьбовое
  отверстие, новое тело, булева операция, массивы и зеркало тел, удаление тела проверены
  сквозными тестами интерфейса (`tests/e2e-modeling/{phase2_features,bodies}.spec.ts`);
  траектория из цепочки рёбер модели — только через API модуля; у операции по сечениям нет
  направляющих кривых; резьба условная (атрибуты грани), на чертеже изображается по ГОСТ 2.311
  (`docs/drawing/ANNOTATIONS.md`); дерево линейное.
- Вид сам вписывает модель при открытии документа и после операции, добавившей тела вне кадра
  (массив, зеркало, копия); при обычных правках камера не меняется — если модель ушла из кадра
  (выдавливание стало длиннее), нажмите F.
- Импорт DXF в эскиз: без сплайнов, эллипсов, блоков, штриховок и текстов; ограничения не
  распознаются; пересечения кривых не разрезаются.
- Касательная плоскость строится к бесконечному цилиндру: принадлежность линии касания
  грани не проверяется.
- Вершины выбираются только для слотов операций (вспомогательная геометрия); рамочного
  выбора и фильтров выбора нет.
- Связь операции нельзя очистить правкой; необязательные связи задаются при добавлении.
- Ссылки, выбранные в прошлых сессиях, в панели редактирования показываются именами без
  подсветки.
- Смещения текстов размеров эскиза не сохраняются в файл детали (материал и плотность
  сохраняются отдельным полем `material`, в историю отмены не попадают).
- Сплайн — по полюсам; эквидистанта сплайна и эллипса — приближение, которое при правке
  размера смещения не пересчитывает свою форму; сплайн-проекция ребра требует, чтобы у ребра
  сохранялось число полюсов.
- История отмены — в пределах сессии.

## 13.3. Сборка

- Степени свободы — по подсистемам, без разложения по компонентам.
- Решатель локальный; нет пределов и упоров; зубчатая передача задаётся передаточным
  сопряжением (углы двух осей связаны передаточным отношением).
- Подсборки жёсткие и только для чтения; разнесённый вид и перетаскивание — только
  верхний уровень; экземпляры массивов не участвуют в сопряжениях.
- Поворот при вставке детали — только перетаскиванием или сопряжениями.
- В STEP не пишутся сопряжения, массивы, материал, плотность.
- Крепёж: только крупный шаг, без классов прочности; штифты — вручную.

## 13.4. Чертёж

- Отмена/повтор не охватывают параметры модели и «Обновить по модели»; история не
  сохраняется в файл.
- Нет ломаных разрезов, наложенных и вынесенных сечений, линий обрыва, обозначения
  дополнительного вида стрелкой; штриховка только металлов; в разрезе сборки смежные детали
  штрихуются разным наклоном или шагом, крепёж, валы и подшипники не рассекаются (ГОСТ 2.109,
  2.420; журнал 2026-11-14, 2026-11-20).
- Размеры в интерфейсе — по рёбрам (с цепочками и от базы); к отдельным вершинам — только в
  ядре; автокомпоновка размеров (ГОСТ 2.307) и разнесение позиций (ГОСТ 2.109) работают в
  пределах одного вида, часть выносок остаётся длинной (журнал 2026-11-21).
- Подсборка нумеруется
  одной позицией (сборочная единица), «разборная» — позициями своих деталей (флажок на вкладке
  «Спецификация»); отмена (Ctrl+Z) не снимает флажок «разборная» — снимите его повторным
  щелчком; графа «Зона» не заполняется.
- Файл чертежа хранит копию модели: изменения файла детали приходят через «Заменить модель…».
- Форматы в интерфейсе — А0–А4 без кратных; метод третьего угла не выбирается.
- Шрифт типа Б ГОСТ 2.304 — собственный однолинейный, ширины букв требуют сверки; греческие
  строчные буквы, «@», «…» есть с 2026-11-20; DejaVu Sans для поиска в PDF встраивается целиком (PDF ≈ 0,8 МБ).
- Центровые метки — только для цилиндров.
- Сборка открывается только со встроенной геометрией.

## 13.5. Обмен данными и измерения

- DXF импортируется только в эскиз детали (не подложкой листа чертежа); STL как опорная
  сетка не импортируется; STEP/IGES сторонних CAD не проверялись (`docs/ui/DATA_EXCHANGE.md`).
- Измерения (расстояние, угол, длина, площадь, радиус) работают в детали, просмотре STEP и
  сборке, сечение плоскостью — в детали и просмотре STEP; сечения сборки нет, результат не
  сохраняется в файле и не становится размером чертежа (`docs/ui/KERNEL_VIEWPORT.md`).
  Материал выбирается из библиотеки ядра (21 материал) в «Свойствах» детали.

## 13.6. Платформа

- Каждая вкладка — отдельный модуль ядра (≥ 128 МБ памяти); расчёт одной операции
  однопоточный; прогресс неопределённый.
- «Прервать» теряет историю отмены и незавершённую панель/эскиз.
- Последние файлы и черновики — только в этом браузере; сохранение — скачивание файла.
- Сообщения ядра переводятся по шаблонам (около 85 % сообщений ядра, журнал 2026-11-14); остальные показываются заголовком по коду ошибки («Операция не
  выполнена», «Ошибка чтения файла»…) и исходным английским текстом в «Подробностях».
  Редактор чертежа показывает сообщения ядра как есть. Отдельные страницы редакторов — только
  на русском (переключатель языка есть в оболочке).
- После сбоя модуля ядра (раздел 2.5а) теряются история отмены и прерванное действие.
- Сквозные тесты — только в Chromium.
