# 13. Известные ограничения

Перечень собран по разделам «Ограничения» документов модулей и по коду интерфейса.

## 13.1. Данные стандартов (⚠ требуют сверки)

Записаны без доступа к официальным изданиям; тесты сверяют геометрию с этими же таблицами
и ошибку в таблице не поймают (`docs/STANDARDS_VERIFICATION.md`):

| Что | Стандарт |
|---|---|
| Размеры граф основной надписи форм 1 и 2а | ГОСТ 2.104 |
| Стрелки и буквы обозначений разрезов | ГОСТ 2.305 |
| Размеры болтов, винтов, гаек, шайб, штифтов | ГОСТ 7798, 11738, 5915, 11371, 6402, 3128; ISO 4014, 4017, 4762, 4032, 7089, 2338 |
| Таблица IT, основные отклонения | ISO 286-1/-2, ГОСТ 25346–25347 |
| Запись нулевого отклонения, стрелки размеров | ГОСТ 2.307 |
| Знаки шероховатости, рамки допусков, базы | ГОСТ 2.309, 2.308 |
| Графы спецификации | ГОСТ 2.106, 2.104 |
| Свойства встроенных материалов | EN 1993, EN 1999, ГОСТ 1050 и др. |

## 13.2. Деталь и эскиз

- Нет sweep, loft, ребра жёсткости, резьбовых отверстий и условного изображения резьбы,
  булевых операций между телами; дерево линейное (одно тело или составное тело).
- Точки, ЛСК, плоскости через три точки и касательные — только в библиотеке ядра.
- Выбора вершин, рамочного выбора и фильтров выбора нет.
- Связь операции нельзя очистить правкой; необязательные связи задаются при добавлении.
- Ссылки, выбранные в прошлых сессиях, в панели редактирования показываются именами без
  подсветки.
- Плотность и смещения текстов размеров эскиза не сохраняются в файл детали.
- Сплайн — по полюсам; обрезка и удлинение — только отрезков, дуг и окружностей; проекции
  рёбер модели из редактора эскиза не создаются.
- История отмены — в пределах сессии.

## 13.3. Сборка

- Степени свободы — по подсистемам, без разложения по компонентам.
- Решатель локальный; нет пределов, упоров и кинематических передач.
- Подсборки жёсткие и только для чтения; разнесённый вид и перетаскивание — только
  верхний уровень; экземпляры массивов не участвуют в сопряжениях.
- Поворот при вставке детали — только перетаскиванием или сопряжениями.
- В STEP не пишутся сопряжения, массивы, материал, плотность.
- Крепёж: только крупный шаг, без классов прочности; штифты — вручную.

## 13.4. Чертёж

- Нет отмены/повтора.
- Нет местных, ступенчатых и ломаных разрезов, сечений, линий обрыва, обозначения
  дополнительного вида стрелкой; штриховка только металлов; разрез сборки штрихуется
  одинаково для всех деталей.
- Размеры только по рёбрам; нет цепочек, от базы, к вершинам; нет перетаскивания размеров и
  автокомпоновки.
- Позиции — только через API; графа «Зона» не заполняется.
- Форматы в интерфейсе — А0–А4 без кратных; метод третьего угла не выбирается.
- Шрифт — DejaVu Sans вместо типа Б ГОСТ 2.304; шрифт встраивается целиком (PDF ≈ 0,8 МБ).
- Центровые метки — только для цилиндров.
- Сборка открывается только со встроенной геометрией; сценарий сборки в интерфейсе
  сквозным тестом не проверен.

## 13.5. Обмен данными и измерения

- В интерфейсе нет IGES, STL, 3MF, импорта DXF, экспорта STEP детали.
- Измерений и сечения модели плоскостью во вьюпорте нет; материалы из библиотеки ядра не
  выбираются.

## 13.6. Платформа

- Каждая вкладка — отдельный модуль ядра (≥ 128 МБ памяти); расчёт одной операции
  однопоточный; прогресс неопределённый.
- «Прервать» теряет историю отмены и незавершённую панель/эскиз.
- Последние файлы и черновики — только в этом браузере; сохранение — скачивание файла.
- Панели редакторов не локализованы (только русский).
- Сквозные тесты — только в Chromium.
