# 5. Дерево построения

Дерево построения (feature tree) — упорядоченный список операций детали. Каждая операция
работает с последним валидным телом, полученным выше по дереву. После любой правки
документ перестраивает только изменившуюся часть: операции с теми же входами берут
прежний результат.

## 5.1. Состояния узлов

| Отметка | Состояние | Что значит |
|---|---|---|
| ✓ | «построено» | операция выполнена; ссылки найдены точно или по истории |
| ! | «предупреждение» | выполнена с замечанием: ссылка восстановлена по геометрической сигнатуре, в эскизе есть избыточные ограничения, в результате несколько тел |
| ✕ | «ошибка» | не построена; следующие операции получают последнее валидное тело |
| – | «подавлено» | исключена пользователем; тело проходит дальше без неё |
| · | «за маркером отката» | ниже маркера отката, не вычисляется |

Под узлом выводятся его сообщения. Щелчок по эскизу в дереве показывает его области
полупрозрачным наложением во вьюпорте.

## 5.2. Команды узла

Меню «⋯» справа от узла или правый щелчок:

| Команда | Действие |
|---|---|
| «Редактировать» | открыть панель операции с текущими значениями (раздел 4); «Предпросмотр» / «ОК» / «Отмена» как при создании |
| «Редактировать эскиз» | (только эскиз) открыть редактор эскиза (раздел 3) |
| «Подавить» / «Включить» | подавление (suppress): операция не выполняется, тело проходит дальше |
| «Удалить» | удалить узел |
| «Перенести выше» / «Перенести ниже» | перенос на одну позицию |
| «Откатить до этой операции» | поставить маркер отката сразу после узла |

Маркер отката (rollback) показывается строкой «маркер отката» с кнопкой «Снять». Новая
операция вставляется в позицию маркера — так добавляют операцию «в середину» дерева.
Узлы за маркером нельзя редактировать, пока маркер не снят.

Delete удаляет выбранный узел; Ctrl+Z / Ctrl+Y отменяют и повторяют правки дерева (вне
полей ввода и при закрытой панели). Подсказка кнопок «Отменить»/«Повторить» показывает
имя записи истории. История — до 200 записей, в файл не сохраняется.

## 5.3. Ошибки перестроения и как их исправлять

| Сообщение (пример) | Причина | Что делать |
|---|---|---|
| `has no closed profile` | у эскиза нет замкнутого контура | замкните контур в редакторе эскиза; посмотрите блок «Профиль» |
| `sketch constraint N (тип): …`, список конфликтующих ограничений | конфликт или неверные операнды ограничения | откройте эскиз, удалите или сделайте справочным ограничение из списка «Конфликтующие ограничения» |
| `link 'sketch' …`, «is suppressed», связь «вниз по дереву» | связанный узел отсутствует, подавлен, стоит ниже или не построен | включите связанный узел, перенесите операцию ниже него или выберите другую связь |
| `edge '…' was removed by feature 'Chamfer001' (replaced by …)` | выбранное ребро удалено более ранней операцией | откройте «Редактировать» и выберите ребро заново (или перенесите операцию выше удаляющей) |
| `no edge … with a matching signature`, `signature is ambiguous` | элемент не найден ни по имени, ни по истории, ни по сигнатуре | выберите элемент заново |
| `tool does not intersect` | вырез или массив выреза не задевает тело | измените положение эскиза, глубину или шаг |
| список рёбер скругления с причиной | OCCT не построил скругление | уменьшите радиус, уберите проблемные рёбра |
| `unknown variable 'Q'`, `cyclic dependency A -> B -> A` | ошибка выражения | исправьте выражение или переменную (раздел 6) |
| `InvalidInput: …` в строке ошибки страницы | неверное значение в поле панели (например, пустое выражение) | исправьте поле; узел не создаётся |

Ссылка, найденная в нескольких элементах, в слоте «одна ссылка» — тоже ошибка;
частичного применения операции нет.

## 5.4. Топологические ссылки

Выбранная во вьюпорте грань или ребро хранится не номером, а **устойчивым именем**
(topological name) и геометрической сигнатурой. Имя строится по истории операций,
например:

| Элемент выдавливания `Body` эскиза `Profile` | Имя |
|---|---|
| боковая грань от отрезка 3 | `G[Body](Profile:E3)` |
| верхний торец | `G[Body](Profile:R1)` |
| боковое ребро от вершины отрезков 1 и 4 | `G[Body](Profile:V1_4)` |

Имена не содержат размеров, поэтому переживают любые изменения размеров эскиза и вставку
операций выше по дереву, пока не меняется состав кривых эскиза. Без открытой панели щелчок
по грани показывает её имя в «Свойствах».

Порядок разрешения ссылки при перестроении: точно по имени → по истории (элемент
переименован, слит или расщеплён — ссылка указывает на все части) → по журналу удалений
(элемент заменён порождённым) → по геометрической сигнатуре (ближайший похожий элемент,
только если он однозначен; узел получает «предупреждение»). Если ни один способ не дал
однозначного ответа, ссылка считается сломанной, и узел получает ошибку с причиной —
система не угадывает.

Когда ссылки могут сломаться:

- удаление и повторное создание кривых эскиза (новые номера) — ссылки ниже разрешаются
  только по сигнатуре;
- удаление операции и создание такой же новой — её грани получают новый идентификатор;
- зеркально-симметричные элементы одинакового размера сигнатура не различает — такие
  ссылки объявляются неоднозначными.

На тестовом наборе из 11 эталонных деталей и 98 сценариев изменения размеров сохранились
все 338 проверенных ссылок; на модели с 6 ссылками и 27 сценариями — все 162.
