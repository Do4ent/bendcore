# 6. Переменные и выражения

Параметр операции, размер эскиза, координата закреплённой точки и переменная документа —
это выражение (expression). Изменение переменной перестраивает всё, что от неё зависит.

## 6.1. Панель «Переменные» (страница детали)

Левая панель под деревом построения:

- новая переменная — поля «имя» и «выражение», кнопка «+»;
- у каждой переменной — выражение и вычисленное значение (или ошибка); правка выражения
  применяется по выходу из поля;
- крестик — удалить переменную.

В выражениях параметров, размеров эскиза и других переменных переменную пишут по имени
(`W`) или с префиксом `$` (`$W`).

## 6.2. Синтаксис

| Элемент | Запись |
|---|---|
| Числа | `60`, `2.5` (десятичная точка; экспоненциальная запись не поддерживается) |
| Операции | `+ - * / ^`, скобки |
| Функции | `sqrt`, `abs`, `sin`, `cos`, `tan`, `min`, `max`, `floor`, `ceil`, `round` |
| Единицы | длины — мм; углы параметров операций и ограничений эскиза — градусы |

Примеры: `W/2`, `sqrt(W^2 + H^2)`, `max(3, T*0.1)`, `D + 2*S`.

Переменные вычисляются в порядке зависимостей. Ошибки:

- неизвестное имя — `unknown variable 'Q'`;
- цикл — все переменные цикла получают `cyclic dependency A -> B -> A`.

Неверное выражение в поле панели операции не даёт создать узел (`InvalidInput` в строке
ошибки страницы); ошибка в переменной переводит зависящие узлы в состояние «ошибка».

## 6.3. Переменные в чертеже

Правая панель редактора чертежа показывает параметры модели. Изменение (Enter или уход с
поля) перестраивает деталь и сообщает, что изменится в чертеже; сам чертёж меняется только
по кнопке «Обновить по модели» (раздел 8). Значение, при котором деталь не строится,
отвергается, параметр восстанавливается.

## 6.4. Таблица параметров (исполнения)

Блок «Таблица параметров» над «Переменными» хранит исполнения детали — как Design Table или
«Исполнения» КОМПАС. Строка — исполнение: обозначение и наименование. Первая строка — базовое
исполнение с полным обозначением (`РЦ.080.00.010`), у остальных можно писать суффикс (`-01`,
`-02`): полное обозначение — `РЦ.080.00.010-01` (ГОСТ 2.113). Столбцы:

- переменная (`W`, `H`, …) — выражение, как в панели «Переменные»;
- «Подавить: <операция>» — операция активна или подавлена в этом исполнении;
- «Материал» — материал библиотеки; масса детали считается по нему.

Пустая ячейка — «как в детали»: берётся значение из панели «Переменные» (или флаг подавления
операции в дереве, или материал блока «Свойства»).

Работа:

1. «+ Столбец» добавляет переменную, подавление или материал; ячейки получают текущие значения.
2. «+ Исполнение» копирует последнюю строку со следующим суффиксом; поля строки правятся на
   месте, крестик удаляет строку или столбец.
3. Переключатель «Акт.» выбирает активное исполнение: его значения подставляются в переменные,
   деталь перестраивается. «Базовые значения» — без исполнения.
4. Пока исполнение активно, правка переменной или подавление операции, которые задаёт его
   ячейка, меняет **эту ячейку**, а не базовое значение.
5. «Проверить все» строит каждое исполнение и отмечает ✓ или «!» с причиной («feature 'Body'
   is not built…»); активное исполнение не меняется.
6. «Экспорт CSV» и «Импорт CSV…» — файл для Excel: разделитель `;`, числа с десятичной запятой
   или точкой (выбор рядом с кнопкой), первая строка — заголовки `designation;name;W;D;H;
   suppress:Hole;material` (при импорте понимаются и «Обозначение», «Наименование»,
   «подавить:Hole», «Материал»).
7. Ctrl+Z отменяет любую правку таблицы и выбор исполнения.

Ошибки показываются сразу, таблица при этом не меняется: неизвестная переменная или операция,
недопустимое значение (`8O+`, «maybe» вместо 1/0, неизвестный материал), повтор обозначения,
ошибка CSV с номером строки. Таблица и активное исполнение сохраняются в файле детали (формат
v4); старые файлы без таблицы открываются как раньше.

В сборке исполнение выбирается у компонента: «Свойства» → «Исполнение» (`docs/USER_GUIDE`,
раздел сборки; `docs/ui/ASSEMBLY_UI.md`). Масса, BOM и спецификация считаются по исполнению;
исполнения в спецификации — отдельные строки со своими обозначениями.

## 6.5. Ограничения

- Столбцы таблицы параметров — только переменные, подавление операций и материал; размер
  эскиза или параметр операции попадает в таблицу через переменную.
- Исполнений сборок (таблицы параметров у сборки) и групповой спецификации ГОСТ 2.113 нет.
- В сборке значения сопряжений (расстояние, угол) — числа, не выражения.
