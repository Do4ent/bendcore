# 6. Переменные и выражения

Параметр операции, размер эскиза, координата закреплённой точки и переменная документа —
это выражение (expression). Изменение переменной перестраивает всё, что от неё зависит.

## 6.1. Панель «Переменные» (страница детали)

Левая панель под деревом построения:

- новая переменная — поля «имя» и «выражение», кнопка «+»;
- у каждой переменной — выражение и вычисленное значение (или ошибка); правка выражения
  применяется по выходу из поля;
- крестик — удалить переменную.

В выражениях параметров, размеров эскиза и других переменных переменную пишут по имени
(`W`) или с префиксом `$` (`$W`).

## 6.2. Синтаксис

| Элемент | Запись |
|---|---|
| Числа | `60`, `2.5` (десятичная точка; экспоненциальная запись не поддерживается) |
| Операции | `+ - * / ^`, скобки |
| Функции | `sqrt`, `abs`, `sin`, `cos`, `tan`, `min`, `max`, `floor`, `ceil`, `round` |
| Единицы | длины — мм; углы параметров операций и ограничений эскиза — градусы |

Примеры: `W/2`, `sqrt(W^2 + H^2)`, `max(3, T*0.1)`, `D + 2*S`.

Переменные вычисляются в порядке зависимостей. Ошибки:

- неизвестное имя — `unknown variable 'Q'`;
- цикл — все переменные цикла получают `cyclic dependency A -> B -> A`.

Неверное выражение в поле панели операции не даёт создать узел (`InvalidInput` в строке
ошибки страницы); ошибка в переменной переводит зависящие узлы в состояние «ошибка».

## 6.3. Переменные в чертеже

Правая панель редактора чертежа показывает параметры модели. Изменение (Enter или уход с
поля) перестраивает деталь и сообщает, что изменится в чертеже; сам чертёж меняется только
по кнопке «Обновить по модели» (раздел 8). Значение, при котором деталь не строится,
отвергается, параметр восстанавливается.

## 6.4. Ограничения

- Таблиц параметров и конфигураций (исполнений) нет.
- В сборке значения сопряжений (расстояние, угол) — числа, не выражения.

## Где проверено

- Вычисление выражений: `src/formula.cpp`, тест `test_formula_comprehensive`; правила
  переменных — `docs/modeling/PART_DOCUMENT.md`, раздел «Выражения».
- Панель: `src/ui/modeling/PartModelerApp.tsx` (блок «Переменные»); переменные в выражениях
  эскиза — `tests/wasm/sketch_editor.test.mjs`; неверное выражение — `tests/e2e-modeling/part_modeling.spec.ts`.
- Запрет экспоненциальной записи: `docs/ui/SKETCH_EDITOR.md` («парсер выражений её не знает»).
- Чертёж: `setVariable` в `src/wasm/bendcore_drawing_api.d.mts`, `tests/wasm/drawing_document.test.mjs`
  (A = 80, d = 10; деталь, которая не строится, — отказ с восстановлением параметра).
- Значения сопряжений — числа: `src/ui/assembly/AssemblyPanels.tsx` (`MatePanel`, `num(value)`).
