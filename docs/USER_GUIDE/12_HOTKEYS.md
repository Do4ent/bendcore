# 12. Горячие клавиши

Слушает только активная вкладка. Клавиши, набранные в поле ввода, остаются полю (кроме
Esc). На macOS вместо Ctrl можно нажимать Cmd.

## 12.1. Общие

| Клавиши | Деталь | Сборка | Чертёж |
|---|---|---|---|
| Ctrl+Z | отменить | отменить | — |
| Ctrl+Y, Ctrl+Shift+Z | повторить | повторить | — |
| Ctrl+S | сохранить | сохранить | сохранить (два файла) |
| Ctrl+O | открыть | открыть | открыть чертёж |
| Esc | закрыть панель операции (отмена) | сбросить выбор и слоты сопряжения | инструмент «Выбор», сброс выбранных рёбер и вида |
| Delete | удалить выбранный узел дерева | удалить выбранный компонент | удалить выбранный вид |
| F | показать всё | показать всё | — |

На стартовой странице Ctrl+O открывает диалог «Открыть файл…». В детали Ctrl+Z/Ctrl+Y
действуют при закрытой панели операции.

## 12.2. Редактор эскиза

| Клавиши | Действие |
|---|---|
| Esc | отменить ввод размера → сбросить начатую фигуру → вернуться к «Выбору» |
| Enter | завершить цепочку отрезков или сплайн |
| Delete, Backspace | удалить выбранное |
| Ctrl+Z | «Шаг назад» внутри эскиза |
| Shift + щелчок | добавить к выбору |
| двойной щелчок | закончить цепочку отрезков; по тексту размера — правка выражения |

## 12.3. Редактор чертежа

| Клавиши | Действие |
|---|---|
| Enter | в инструменте «Размер» — размер по одной выбранной окружности или дуге |
| Esc | отмена выбора рёбер, инструмент «Выбор» |

## 12.4. Мышь

| Где | Действие |
|---|---|
| Вьюпорт детали и сборки | вращение, сдвиг, масштаб камеры (OrbitControls) |
| Эскиз | колесо — масштаб к курсору, средняя или правая кнопка — сдвиг |
| Лист чертежа | колесо — масштаб вокруг курсора, средняя кнопка или перетаскивание свободного места — панорама |

Клавиш Ctrl+N, Ctrl+Shift+S, Ctrl+P и других, перечисленных в старом
`docs/GUIDES/KEYBOARD_SHORTCUTS.md`, в интерфейсе нет.
