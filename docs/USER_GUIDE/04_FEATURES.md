# 4. Операции детали

Операция (feature) — узел дерева построения: входы (эскиз, выбранные грани и рёбра,
параметры) → новое тело. Все операции выполняет геометрическое ядро OCCT; булевы
операции идут с проверкой результата и лечением геометрии.

## 4.1. Общий порядок работы с панелью операции

1. Нажмите кнопку типа на панели инструментов. Открывается панель; документ начинает
   транзакцию.
2. Заполните разделы панели:
   - «Параметры (выражения)» — числа или выражения с переменными документа (раздел 6);
     после предпросмотра рядом показывается вычисленное значение;
   - «Настройки» — списки (режим, граница, тип и т. п.);
   - «Связи» — более ранние узлы нужного типа (эскиз, операция для массива,
     вспомогательная плоскость или ось); по умолчанию выбран последний подходящий;
   - «Элементы модели» — слоты граней и рёбер: «Выбрать во вьюпорте», щелчок по грани или
     ребру; повторный щелчок убирает элемент; «Готово» завершает выбор. Пока слот
     активен, вьюпорт показывает тело на входе операции.
3. «Предпросмотр» — добавляет узел и перестраивает: вьюпорт, «Свойства» и состояние узла
   показывают результат.
4. «ОК» — применить (одна запись истории отмены); «Отмена» — откатить транзакцию.

Поле «Имя» задаёт подпись узла в дереве; без него используется идентификатор вида
`Extrude001`.

Ошибка построения не прерывает работу: узел получает состояние «ошибка» и сообщение,
следующие операции получают последнее валидное тело (раздел 5).

## 4.2. Выдавливание — «Выдавливание» (Extrude)

Назначение: тело или вырез заметанием профиля эскиза по нормали к его плоскости.

| Поле | Значения |
|---|---|
| «Режим» | «добавить» (boss) — объединение с телом; «вырезать» (cut) — вычитание |
| «Граница» | «на глубину» (Расстояние); «симметрично» (Расстояние всего, по половине в каждую сторону); «в две стороны» (Расстояние вперёд, Расстояние 2 назад); «через всё»; «через всё в обе стороны»; «до грани» (слот «Граница (грань)»); «до поверхности» (поверхность выбранной грани, продолженная) |
| «Обратное направление» | выдавливание против нормали эскиза |
| «Угол уклона, °», «Направление уклона» | уклон боковых граней от плоскости эскиза: «внутрь» (сужение) или «наружу», 0 ≤ угол < 90° |
| «Тонкостенное», «Толщина, мм» | «нет»; «внутрь» / «наружу» — стенка вдоль всех контуров профиля без торцов |
| Связь «Эскиз» | эскиз с замкнутым профилем; каждая выбранная область выдавливается |

Ограничения:

- Уклон — только при односторонних границах («на глубину», «через всё», «до грани», «до
  поверхности») и не вместе с тонкостенным (ошибка `Unsupported`). На сплайновых боковых
  гранях уклон может не построиться.
- «Вырезать» требует тела и пересечения с ним: вырез мимо тела — ошибка «tool does not
  intersect».
- «До грани» / «до поверхности»: прямые вдоль направления выдавливания должны пересекать
  ограничитель один раз, и грань должна перекрывать профиль; смещение от ограничителя не
  задаётся.

## 4.3. Вращение — «Вращение» (Revolve)

Назначение: тело вращения профиля эскиза вокруг оси.

| Поле | Значения |
|---|---|
| «Режим» | «добавить» / «вырезать» |
| «Граница» | «полный оборот»; «на угол» (Угол); «симметрично» (Угол всего); «в две стороны» (Угол, Угол 2) |
| «Ось» | «линия эскиза» — номер отрезка эскиза в поле «Ось: сущность эскиза» (номер кривой, как «к3» в списке ограничений; удобно рисовать ось вспомогательной геометрией); X, Y, Z; «ребро» (слот «Ребро оси»); «вспомогательная» (связь «Ось») |
| «Обратное направление» | меняет направление оси |

Ограничения: ось лежит в плоскости эскиза; профиль — по одну сторону от оси; суммарный
угол — больше 0 и не больше 360°.

## 4.4. Отверстие — «Отверстие» (Hole)

Назначение: отверстие по форме сверла в плоской грани тела.

| Поле | Значения |
|---|---|
| Слот «Грань» | плоская грань тела, обязательна |
| Центр | «X, мм», «Y, мм», «Z, мм» — точка проецируется на плоскость грани; **или** связь «Эскиз» — по одному отверстию в каждой отдельной точке эскиза (точке, не занятой кривыми; инструмент «Точка», раздел 3) |
| «Тип» | «простое»; «с цековкой» (Диаметр цековки, Глубина цековки); «с зенковкой» (Диаметр зенковки на грани, Угол зенковки, по умолчанию 90°) |
| «Окончание» | «на глубину» (Глубина — цилиндрической части) или «насквозь» |
| «Конец сверла», «Угол сверла, °» | конус на дне глухого отверстия, по умолчанию 118° |

Направление — в материал, против наружной нормали грани. Диаметры цековки и зенковки
должны быть больше диаметра отверстия, глубина цековки — меньше глубины глухого
отверстия; точка должна лежать внутри грани.

Ограничения: только геометрия отверстия. Для резьбы — операция «Резьбовое отверстие» (ISO 261,
M1–M48; резьба условная, ⚠ требует сверки — `docs/STANDARDS_VERIFICATION.md`).

## 4.5. Скругление — «Скругление» (Fillet)

Скругление рёбер постоянным радиусом. Слот «Рёбра» (несколько), «Радиус, мм» > 0. Если
OCCT не может построить скругление (например, радиус слишком велик), узел получает ошибку
со списком неудавшихся рёбер (номера в списке выбранных и причина) — уменьшите радиус или
уберите эти рёбра.

## 4.6. Фаска — «Фаска» (Chamfer)

Слот «Рёбра»; «Тип»:

| «Тип» | Параметры |
|---|---|
| «равные» | «Расстояние, мм» |
| «два расстояния» | «Расстояние, мм» — по опорной грани, «Расстояние 2, мм» |
| «расстояние и угол» | «Расстояние, мм» по опорной грани, «Угол, °» между опорной гранью и фаской |

Опорная грань — слот «Грань» (должна примыкать к ребру); без неё берётся первая
примыкающая грань с предупреждением.

## 4.7. Массивы и зеркало

Массив (pattern) повторяет **инструмент** исходной операции (выдавливания, выреза,
отверстия) — связь «Операция». Копии применяются одной булевой операцией; экземпляр 0 —
исходный.

**«Линейный массив»** (LinearPattern): «Количество 1», «Шаг 1, мм», «Направление 1» (X,
Y, Z, «ребро» — слот «Ребро направления 1», «вспомогательная» — связь «Ось 1»), «Обратно
1»; второе направление — то же с индексом 2 (по умолчанию «Количество 2» = 1, т. е.
одно направление).

**«Круговой массив»** (CircularPattern): «Количество», «Угол, °», «Ось» (Z, X, Y, «грань»
— ось цилиндрической грани, «ребро», «вспомогательная»), «Шаг»: «равные» — при угле 360°
шаг = угол / количество, иначе угол / (количество − 1); «с шагом» — угол и есть шаг.

**«Зеркало»** (Mirror): «Что отражать» — «операцию» (связь «Операция») или «тело»;
«Плоскость» — YZ, XZ, XY, «грань» (слот «Грань»), «вспомогательная» (связь
«Плоскость»); «Объединить» (для тела) — «да»: тело и копия сливаются, «нет»: два тела в
одном результате (предупреждение «несколько тел»).

Ограничения: вырез, копии которого не задевают тело, — ошибка. Если правка меняет порядок
однотипных граней инструмента, ссылки на грани копий восстанавливаются по сигнатуре
(предупреждение, раздел 5).

## 4.8. Оболочка — «Оболочка» (Shell)

Полое тело с постоянной толщиной стенок. Слот «Грани» — удаляемые грани (может быть
пустым — замкнутая полость), «Толщина, мм», «Направление» — «внутрь» / «наружу». Слишком
большая толщина — ошибка.

## 4.9. Уклон — «Уклон» (Draft)

Литейный уклон граней. Слот «Грани», «Угол, °» (по умолчанию 3), «Нейтраль» — «грань»
(слот «Нейтральная грань»), «вспомогательная» (связь «Плоскость»), XY, XZ, YZ;
«Обратное направление». Положительный угол наклоняет грань внутрь тела по мере удаления
от нейтральной плоскости. Грань, которую OCCT не принимает, даёт ошибку с её номером.

## 4.10. Вспомогательная геометрия — «Плоскость», «Ось»

**«Плоскость»** (DatumPlane), «Способ»:

| «Способ» | Входы |
|---|---|
| «смещение» | «База» — XY, XZ, YZ, «грань» (слот «Грань»), «вспомогательная» (связь «Плоскость»); «Смещение, мм» |
| «на угол» | база и «Ось» — «ребро» (слот «Ребро»), «вспомогательная», X, Y, Z; «Угол, °» |
| «посередине» | две грани (слоты «Грань», «Грань 2») |

**«Ось»** (DatumAxis), «Способ»: X, Y, Z; «грань» — ось цилиндрической или конической
грани; «ребро» — прямое ребро; «пересечение плоскостей» — связи «Плоскость», «Плоскость 2».

Вспомогательные элементы используются как плоскость эскиза, ось вращения, направление и ось
массива, плоскость зеркала, нейтраль уклона. Тело они не меняют.

Ограничения: точки и локальные системы координат, плоскости через три точки и касательные
плоскости есть в библиотеке ядра (`docs/modeling/REFERENCE_GEOMETRY.md`), но как операции
дерева не выведены.

## 4.11. Операции фазы 2: кинематика, по сечениям, ребро, резьбовое отверстие, тела

Кнопки на панели инструментов — из каталога ядра; параметры каждой операции —
`docs/modeling/FEATURES.md`, разделы 8–12.

- **Траектория и контур ребра.** В панели «Эскиз» выберите форму «Траектория (открытая)» —
  настройка «Контур» переключится на «открытый». Вершины — по одной в строке: «x; y» — отрезок
  от предыдущей вершины, «x; y; cx; cy; cw» (или «ccw», по умолчанию) — дуга вокруг центра
  (cx, cy) по часовой (против часовой) стрелке до точки (x, y). Пример — вверх на 30 и
  четверть дуги R20: `0; 0`, `0; 30`, `20; 50; 20; 30; cw`. Все вершины и центры становятся
  размерами эскиза (правка из дерева).
- **«Кинематика»** (Sweep): связь «Эскиз» — профиль (замкнутый контур, можно с отверстиями,
  например кольцо), «Эскиз траектории» — открытый эскиз; начало траектории должно лежать в
  плоскости профиля. Режим «добавить», «вырезать» (канал в теле) или «новое тело».
- **«По сечениям»** (Loft): связи «Сечение 1» … «Сечение 8» — эскизы в разных параллельных
  или наклонных плоскостях (смещение эскиза — поле «Смещение»), по порядку без пропусков;
  «Поверхность» — «гладкая» или «линейчатая» (между окружностями — конус).
- **«Ребро»** (Rib): связь «Эскиз» — открытый контур в средней плоскости ребра, концы которого
  упираются в тело; «Толщина, мм», сторона.
- **«Резьбовое отверстие»** (ThreadedHole): слот «Грань» активен при открытии — щёлкните по
  плоской грани; «Номинал» (M), центр «X, Y, Z» или эскиз с точками; «Окончание» —
  «насквозь» (длина резьбы 0 — вся стенка) или «на глубину».
- **Новое тело и операции над телами.** «Выдавливание» с режимом «новое тело» создаёт
  отдельное тело; «Свойства» показывают сумму объёмов тел. «Булева операция тел»
  (BodyBoolean): слот «Цель» — щелчок по любой грани тела, «Инструменты» — «Выбрать во
  вьюпорте» и щелчки по граням других тел; «Операция» — объединение, вычитание,
  пересечение; «Сохранить инструменты».

Нет: направляющих кривых у операции по сечениям; рисования траектории мышью поверх модели
(траектория задаётся вершинами или в редакторе эскиза).
