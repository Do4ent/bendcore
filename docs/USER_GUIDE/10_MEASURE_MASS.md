# 10. Измерения и масса

## 10.1. Свойства детали

Правая панель «Свойства» страницы детали (без открытой панели операции):

| Поле | Как считается |
|---|---|
| «Объём, мм³» | `BRepGProp` по телам результата; «нет тела», если тел нет |
| «Плотность, кг/м³» | поле страницы, по умолчанию 7850; **в файл детали не сохраняется** |
| «Масса, кг» | V · 10⁻⁹ · ρ |
| «Площадь, мм²» | площадь поверхности |
| «Центр масс» | при наличии тел |
| «Габарит» | мин. и макс. точки |
| «Грани / рёбра» | число элементов |

Щелчок по грани без открытой панели показывает её устойчивое имя (раздел 5).

Для аналитических тел (плоскости, цилиндры, конусы) объём совпадает с формулой с точностью
около 10⁻⁹ относительно.

## 10.2. Масса в сборке и чертеже

- **BOM сборки**: масса = объём детали × плотность из панели «Свойства» сборки; деталь без
  плотности массы не имеет (раздел 7.9). Масса крепежа — из описания изделия
  (⚠ таблицы крепежа не сверены).
- **Чертёж детали**: масса в основной надписи = объём × плотность из «Свойств детали»
  чертежа. **Чертёж сборки**: общая масса по BOM.

## 10.3. Материалы

В ядре есть библиотека из 21 встроенного материала (стали S235, S355, С245, 45, 12Х18Н10Т,
1.4301, 1.4404; алюминиевые сплавы 6082-T6, 5083, 6061-T6, 2024-T3, 7075-T6, АМг6;
Ti-6Al-4V; пластмассы ABS, PA6, POM-H, PC, PMMA, PTFE, PP) и расчёт моментов инерции, но
в интерфейс они **не выведены**: в полях «Материал» вводится текст, плотность задаётся
вручную.

> **⚠ Требует сверки.** Все свойства встроенных материалов записаны по памяти из указанных
> источников (`docs/kernel/ANALYSIS.md`, раздел 1; `docs/STANDARDS_VERIFICATION.md`). Для
> пластмасс значения зависят от марки производителя — берите плотность из паспорта.

## 10.4. Измерения и сечение

Расстояния, углы между плоскими гранями и прямыми рёбрами, длины рёбер, площади граней,
радиусы, координаты вершин и сечение модели плоскостью реализованы в ядре C++
(`bendcore_kernel_analysis`), но **в интерфейс не выведены**. Доступно из интерфейса:

- параметры грани в «Просмотре STEP» (радиус цилиндра, нормаль плоскости, площадь);
- размеры на чертеже как способ измерения (значение берётся из геометрии вида, раздел 8.5);
- справочные размеры эскиза (раздел 3.6).
