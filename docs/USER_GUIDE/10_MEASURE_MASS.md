# 10. Измерения и масса

## 10.1. Свойства детали

Правая панель «Свойства» страницы детали (без открытой панели операции):

| Поле | Как считается |
|---|---|
| «Объём, мм³» | `BRepGProp` по телам результата; «нет тела», если тел нет |
| «Материал» | «Свой» или один из 21 материала библиотеки; выбор подставляет плотность (раздел 10.3) |
| «Плотность, кг/м³» | по умолчанию 7850; сохраняется в файле детали вместе с материалом |
| «Масса, кг» | V · 10⁻⁹ · ρ |
| «Площадь, мм²» | площадь поверхности |
| «Центр масс» | при наличии тел |
| «Габарит» | мин. и макс. точки |
| «Грани / рёбра» | число элементов |

Щелчок по грани без открытой панели показывает её устойчивое имя (раздел 5).

Блок «Свойства документа» той же панели: «Обозначение», «Наименование», «Разработчик»,
«Организация», «Примечание». Значение записывается, когда поле теряет фокус (или по Enter);
каждое изменение отменяется Ctrl+Z. Свойства сохраняются в файле детали и используются:

- в сборке — имя компонента (наименование), обозначение, наименование, материал и плотность
  в BOM и спецификации, «Примечание» спецификации;
- в STEP — обозначение (PRODUCT id) и наименование;
- в основной надписи чертежа детали — обозначение, наименование, материал, масса, организация,
  разработчик: при создании чертежа и при каждом «Обновить по модели». Графа, заполненная
  вручную на листе, имеет приоритет и при обновлении не меняется.

У исполнения из таблицы параметров с обозначением-суффиксом («-01») полное обозначение —
обозначение детали + суффикс («АБВГ.715311.001-01»).

Для аналитических тел (плоскости, цилиндры, конусы) объём совпадает с формулой с точностью
около 10⁻⁹ относительно.

## 10.2. Масса в сборке и чертеже

- **BOM сборки**: масса = объём детали × плотность из панели «Свойства» сборки; деталь без
  плотности массы не имеет (раздел 7.9). Масса крепежа — из описания изделия
  (⚠ таблицы крепежа не сверены).
- **Чертёж детали**: масса в основной надписи = объём × плотность из «Свойств детали»
  чертежа. **Чертёж сборки**: общая масса по BOM.

## 10.3. Материалы

В блоке «Свойства» страницы детали список «Материал» содержит 21 материал библиотеки ядра:
стали (S235, S355, С245, 45), нержавеющие (12Х18Н10Т, 1.4301, 1.4404), алюминиевые сплавы
(6082-T6, 5083, 6061-T6, 2024-T3, 7075-T6, АМг6), Ti-6Al-4V, пластмассы (ABS, PA6, POM-H, PC,
PMMA, PTFE, PP). Выберите материал: поле «Плотность» получит его значение, «Масса» пересчитается,
файл станет изменённым. **Сохранить** записывает материал и плотность в файл детали; при
открытии они восстанавливаются. Если ввести плотность вручную, материал станет «Свой». В
подсказке варианта — источник значения или пометка «не сверено».

> **⚠ Требует сверки.** Все свойства встроенных материалов записаны по памяти из указанных
> источников (`docs/kernel/ANALYSIS.md`, раздел 1; `docs/STANDARDS_VERIFICATION.md`). Для
> пластмасс значения зависят от марки производителя — берите плотность из паспорта.

В сборке и на чертеже по-прежнему вводится текст материала и плотность в «Свойствах» детали
(раздел 10.2): материал из файла детали туда автоматически не переносится.

## 10.4. Измерения и сечение

**Измерения** (страница детали, «Просмотр STEP», сборка). Панель «Измерения» → «Измерять», затем
выберите, что измерить:

- «Расстояние между элементами» — выберите два элемента (грани или рёбра, переключатель
  «Грани» / «Рёбра»); показываются кратчайшее расстояние и линия между ближайшими точками;
- «Угол между гранями или рёбрами» — две плоские грани или два прямых ребра, 0…180°;
- «Длина ребра», «Площадь грани», «Радиус ребра или грани» (и диаметр) — один элемент.

Повторный щелчок по выбранному элементу снимает выбор; после полного набора следующий щелчок
начинает новое измерение. «Закончить измерения» убирает результат. В сборке расстояния и углы
берутся в мировых координатах между элементами разных компонентов.

**Сечение** (деталь и «Просмотр STEP»). «Сечение» → «Показать сечение»: выберите ось нормали
плоскости (X, Y, Z) и двигайте ползунок вдоль габарита модели; отсечённая часть не показывается,
красная линия — контур сечения, «Площадь сечения» — площадь по ядру. «Оставить другую сторону»
меняет сторону отсечения.

**Сечение сборки.** В сборке та же панель «Сечение»: плоскость X, Y или Z и ползунок вдоль габарита
сборки; «Площадь сечения» — сумма площадей сечений всех деталей (детали, перекрывающиеся в
сечении, считаются дважды), красные линии — контуры.

Нет: сохранения измерений и превращения их в размеры чертежа, расстояния между точками «в воздухе». Справочные размеры эскиза — раздел 3.6; размеры чертежа
берутся из геометрии вида (раздел 8.5).

## 10.5. Выбор: фильтры и рамка

Панель «Выбор» (деталь, «Просмотр STEP», сборка):

- **Что выбирать.** «Грани», «Рёбра», «Вершины», «Тела» (в сборке режимы «Грани», «Рёбра»,
  «Компоненты» переключаются вверху страницы; вершины в сборке не выбираются).
- **Фильтры по типу.** Для граней «Плоские» и «Цилиндрические», для рёбер «Прямые» и «Круговые».
  Ничего не отмечено — выбираются любые; фильтр действует на подсветку при наведении, щелчок,
  рамку и слоты операций. Подсвечиваются только допустимые элементы.
- **Рамка.** «Выбор рамкой», затем потяните левую кнопку: **слева направо** — выбираются
  элементы, целиком попавшие в рамку, **справа налево** — и задетые рамкой. Shift добавляет к
  выбору, Ctrl убирает из него; щелчок с Shift или Ctrl действует так же. Расчёт идёт по
  проекции на экран без учёта закрытости: попадают и невидимые за гранями элементы.
- Под кнопками: число выбранных элементов и итог от ядра (площадь граней, длина рёбер).
- В слоте операции (например, рёбра скругления) вид элемента задаёт слот, а фильтры и рамка
  выбирают элементы в него: Shift добавляет, Ctrl убирает.
