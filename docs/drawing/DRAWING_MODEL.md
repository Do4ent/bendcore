# Модель чертежа `bendcore_drawing_v2`

Назначение: 2D-модель листа чертежа в миллиметрах, оформление по ЕСКД (рамка, основная
надпись) или ISO (рамка ISO 5457, основная надпись ISO 7200) и экспорт (см. `EXPORT.md`). Модуль не зависит от OCCT и от старого `src/drawing`;
виды с HLR, разрезы и осевые линии (фаза 4, пп. 2–4) строит модуль
`bendcore_drawing_views` поверх этой модели — см. `VIEWS.md`.

- Заголовки: `include/bendcore/drawing_v2/` (`sheet.hpp`, `line_types.hpp`, `model.hpp`,
  `title_block.hpp`, `truetype_font.hpp`, `export.hpp`), namespace `bendcore::drawing_v2`.
- Исходники: `src/drawing_v2/`; сборка: `cmake/drawing.cmake` (цель `bendcore_drawing_v2`).
- Ошибки — `kernel::Result` / `Status` с кодом и сообщением; исключения не выбрасываются.

## Система координат

Миллиметры листа, начало — левый нижний угол листа, ось Y вверх, углы — градусы против
часовой стрелки от оси X. Масштаб изображения (ГОСТ 2.302) — забота построителя видов:
модель хранит уже отмасштабированную геометрию листа.

## Листы — ГОСТ 2.301-68, ISO 216

| Функция | Что даёт |
|---|---|
| `gostSheet(base, 1, o)` | Основные форматы, табл. 1: А0 841×1189, А1 594×841, А2 420×594, А3 297×420, А4 210×297 |
| `gostSheet(base, n, o)` | Дополнительные, табл. 2: А0×2, ×3; А1×3, ×4; А2×3…×5; А3×3…×7; А4×3…×9 (размеры — из таблицы, например А4×3 = 297×630, А2×3 = 594×1261). Прочие кратности — ошибка |
| `iso216Sheet(n, o)` | ISO 216, ряд A0…A10 (A5 148×210 … A10 26×37) |
| `iso5457Sheet(n, k, o)` | ISO 5457, разд. 2: k = 1 — основной A0…A4 (ISO 216); иначе удлинённый формат — «специальный» (табл. 2: A3×3, A3×4, A4×3…×5) или «исключительный» (табл. 3: A0×2, ×3; A1×3, ×4; A2×3…×5; A3×5…×7; A4×6…×9). Размеры те же, что у дополнительных форматов ГОСТ 2.301, табл. 2; имя «ISO A3x3» |
| `sheetMultipliers(base)` | Допустимые кратности формата: 1 и кратности табл. 2 (список форматов интерфейса) |

Документ чертежа (`SheetDef::format` — основной формат, кратность, ориентация) строит лист ЕСКД
через `gostSheet`, лист ISO 7200 — через `iso5457Sheet`. Рамка и основная надпись не зависят от
кратности: поля рамки ГОСТ 2.104 (20/5) и ISO 5457 (20/10) отсчитываются от края листа,
основная надпись — в правом нижнем углу рамки (ГОСТ 2.104, п. 4.1; ISO 5457, п. 3.2), графы
19–23 — вдоль левой линии рамки снизу. Ограничение «на А4 — только вдоль короткой стороны»
(ГОСТ 2.104) применяется только к основному А4: А4×3 и др. допускаются в обеих ориентациях.

`Orientation::Portrait` — короткая сторона горизонтально.

## Типы линий — ГОСТ 2.303-68, табл. 1

`s` задаётся при создании чертежа (`Drawing::create(sheet, s)`), допустимо 0,5…1,4 мм.

| `LineType` | Наименование | Толщина: по умолч. (диапазон) | Шаблон по умолч., мм (диапазон ГОСТ) |
|---|---|---|---|
| `SolidThick` | Сплошная толстая основная | s | — |
| `SolidThin` | Сплошная тонкая | s/2 (s/3…s/2) | — |
| `SolidWavy` | Сплошная волнистая | s/2 (s/3…s/2) | — (форма: `makeWavyLine`) |
| `Dashed` | Штриховая | s/2 (s/3…s/2) | штрих 4 (2…8), промежуток 1,5 (1…2) |
| `DashDotThin` | Штрихпунктирная тонкая | s/2 (s/3…s/2) | штрих 15 (5…30), промежуток 3 (3…5) с точкой |
| `DashDotThick` | Штрихпунктирная утолщённая | 2s/3 (s/2…2s/3) | штрих 6 (3…8), промежуток 3 (3…4) с точкой |
| `Open` | Разомкнутая | 1,5s (s…1,5s) | отдельные штрихи 8…20 мм — только `LineSeg` такой длины |
| `SolidThinZigzag` | Сплошная тонкая с изломами | s/2 (s/3…s/2) | — (форма: `makeZigzagLine`) |
| `DashDotDot` | Штрихпунктирная с двумя точками тонкая | s/2 (s/3…s/2) | штрих 15 (5…30), промежуток 5 (4…6) с двумя точками |

Шаблон хранится в соглашении DXF (`>0` штрих, `<0` промежуток, `0` точка). Значения
можно заменить (`Drawing::setLineTypeSpec`) — замена проверяется на диапазоны таблицы 1
(толщина, длина штриха, промежуток между штрихами, число точек). Для векторного вывода
(`renderDashArray`) точка рисуется штрихом длиной в толщину линии, а соседние промежутки
уменьшаются на половину этой длины — период шаблона не меняется.

Волнистая линия — ломаная по синусоиде (32 точки на волну, число волн округляется, концы
точно в заданных точках); линия с изломами — ломаная с `count` зигзагами. Размеры волны и
излома в ГОСТ 2.303 показаны на рисунке таблицы 1 без численных допусков; значения по
умолчанию (амплитуда 1, длина волны 8; излом 4×5 мм) выбраны по изображению и задаются
параметрами.

## Слои и примитивы

Слой — ASCII-имя `[A-Za-z0-9_-]` и цвет ACI 1…255 (используется в DXF); слой `0` есть
всегда. `Entity = {geometry, layer, lineType}`; `geometry` — одно из:

| Примитив | Поля | Проверки `Drawing::add` |
|---|---|---|
| `LineSeg` | `a`, `b` | ненулевая длина; для `Open` — длина 8…20 |
| `Arc` | центр, радиус, `startDeg` → `endDeg` против ч. с. | радиус > 0, ненулевой угол |
| `Circle` | центр, радиус | радиус > 0 |
| `Polyline` | точки, `closed` | ≥ 2 точки (замкнутая ≥ 3) |
| `Text` | точка, UTF-8, `height`, `rotationDeg`, `slanted`, `widthFactor`, `hAlign`, `vAlign` | высота из ряда ГОСТ 2.304: 2,5; 3,5; 5; 7; 10; 14; 20 (h — высота прописных); корректный UTF-8 без управляющих символов; `widthFactor` 0,5…1,0 |
| `Hatch` | контуры, `angleDeg` (45 по умолч.), `spacing` | ГОСТ 2.306: тонкая сплошная линия, шаг 1…10 мм; контуры ≥ 3 точек |
| `SolidFill` | вершины выпуклого многоугольника | 3…64 вершины, выпуклый, ненулевая площадь; не разомкнутая линия. Стрелки, треугольник базы, точка выноски (`ANNOTATIONS.md`) |

Все координаты должны быть конечными. Сплайн не реализован (см. «Ограничения»).

Текст: `slanted = true` — наклон 75° к основанию строки (ГОСТ 2.304), выводится сдвигом
на 15° (в DXF — oblique 15°). Выравнивание: `Left/Center/Right` по горизонтали;
`Baseline` / `Middle` (середина высоты прописных) / `Top` (верх прописных).

Штриховка (`hatchSegments`): контуры переводятся в систему «вдоль/поперёк» линий, линии
проводятся на расстояниях `(k + 1/2)·spacing` от начала координат листа (одинаковая фаза у
соседних областей одной детали), пересечения с рёбрами — по полуоткрытому правилу, пары
точек — по правилу чётности, поэтому вложенный контур становится отверстием. При экспорте
штриховка выводится отрезками (см. `EXPORT.md`).

## Рамка и основная надпись — ГОСТ 2.104-2006

`addFrameAndTitleBlock(drawing, data, options)` добавляет линии и тексты на слои `FRAME` и
`TITLE` (создаются при необходимости) и возвращает `TitleBlockLayout` с прямоугольниками
листа, рамки, основной надписи и граф.

- Линия обреза — граница листа, тонкая.
- Рамка — сплошная толстая основная, поля: 20 мм слева, 5 мм сверху, справа, снизу.
- Основная надпись — в правом нижнем углу рамки, 185 мм шириной. На А4 — только при
  книжной ориентации (вдоль короткой стороны), иначе ошибка.

Форма 1 (185×55, координаты от левого нижнего угла надписи, мм):

| Графа | Содержимое | x | y | Размер |
|---|---|---|---|---|
| 1 | Наименование | 65…135 | 15…40 | 70×25 |
| 2 | Обозначение | 65…185 | 40…55 | 120×15 |
| 3 | Материал | 65…135 | 0…15 | 70×15 |
| 4 | Литера (3 клетки по 5) | 135…150 | 20…35 | 15×15 |
| 5 | Масса | 150…167 | 20…35 | 17×15 |
| 6 | Масштаб | 167…185 | 20…35 | 18×15 |
| 7 | Лист | 135…155 | 15…20 | 20×5 |
| 8 | Листов | 155…185 | 15…20 | 30×5 |
| 9 | Организация | 135…185 | 0…15 | 50×15 |
| 10–13 | Разраб., Пров., Т.контр., (резерв), Н.контр., Утв.: должность / фамилия / подпись / дата | 0…17 / 17…40 / 40…55 / 55…65 | 0…30 (6 строк по 5) | |
| 14–18 | Изменения: Изм. / Лист / № докум. / Подп. / Дата | колонки 7, 10, 23, 15, 10 | 35…55 (4 строки); заголовок — 30…35 | |

Заголовки «Лит.», «Масса», «Масштаб» — строка 35…40 правой части. Толстые линии: контур,
вертикали левой части, границы строки заголовка (y = 30 и 35), границы граф 1–9; тонкие —
остальные строки левой части и разделители клеток литеры.

Форма 2 (185×40, первый лист текстовых документов — спецификации ГОСТ 2.106): таблица граф —
`SPECIFICATION.md`.

Форма 2а (185×15, последующие листы): колонки 7, 10, 23, 15, 10 (две строки изменений
5…15 и заголовок 0…5), графа 2 — 65…175 (110×15), графа 7 — 175…185 (подпись «Лист» в
верхних 7 мм, номер — в нижних 8 мм).

Дополнительные графы 19–23 (`storageStrip`, по умолчанию включены): вдоль левой линии
рамки в поле подшивки, 12 мм (5 — наименование графы, повёрнуто на 90°; 7 — значение),
длины снизу вверх 25, 35, 25, 25, 35 (всего 145): «Инв. № подл.», «Подп. и дата»,
«Взам. инв. №», «Инв. № дубл.», «Подп. и дата».

Заполнение (`TitleBlockData`): обозначение h = 7, наименование 7, материал 5, литера,
масса, масштаб 5, организация 5, остальные 2,5; тексты центрируются в графе (фамилии и
должности — слева с отступом 0,5 мм). Если заданы метрики `FrameOptions::font`
(`TextMetrics`), ширина каждого текста вычисляется по ним. Шрифт типа Б ГОСТ 2.304
(`gostStrokeFont()`, `EXPORT.md`, «Шрифт ГОСТ 2.304») не сжимается: выбирается наибольшая
высота ряда ГОСТ 2.304 (от предпочтительной до 2,5), при которой строка помещается в графу
(например, «Вал ступенчатый» — 105d = 73,5 мм при h = 7 в графу 1 шириной 69 мм не помещается
и пишется h = 5). Шрифт TrueType сначала сжимается (`widthFactor` до 0,6 — у DejaVu Sans
ширина прописных около 1,0 h против 6/10 h у типа Б), затем уменьшается высота. Не помещается
и при 2,5 — ошибка `InvalidInput` с именем графы. Без метрик ширина не проверяется. Дату в
графе 13 (10 мм) пишут в виде «мм.гг».

Шрифт вывода текста листа — `Drawing::setTextFont(TextFont::Gost2304 | TrueType)`; по умолчанию
у листа, созданного `Drawing::create`, — `TrueType`, у листов документа чертежа и спецификации —
`Gost2304` (`DrawingSettings::textFont`).

Источник размеров граф — изображение форм 1 и 2а в ГОСТ 2.104-2006 (размеры проставлены на
рисунках стандарта). Тексты стандартов в репозитории нет; при приёмке нормоконтролёром
таблицу выше следует сверить с официальным изданием.

## Рамка ISO 5457 и основная надпись ISO 7200

`addIsoFrameAndTitleBlock(drawing, Iso7200Data, IsoFrameOptions)` — вариант оформления листа
наряду с ЕСКД (в документе чертежа — `DrawingSettings::sheetStyle = Iso7200`,
`DRAWING_DOCUMENT.md`). Возвращает тот же `TitleBlockLayout`: ключи `graphs` — `int(Iso7200Field)`,
`projectionSymbol` — габарит знака метода проекций.

- Линия обреза — тонкая; рамка — сплошная толстая, поля ISO 5457 (п. 3.2): 20 мм слева (поле
  подшивки), 10 мм сверху, справа, снизу (`kIso5457LeftMargin`, `kIso5457Margin`).
- Метки центрирования ISO 5457 (п. 3.3) на осях симметрии листа — сплошные толстые от края листа
  до 5 мм за линию рамки (`IsoFrameOptions::centringMarks`, по умолчанию включены).
- Основная надпись — в правом нижнем углу рамки, ширина 180 мм (ISO 7200:2004, п. 3.1,
  `kIso7200Width`), высота 36 мм (4 строки по 9 мм). На А4 книжной — во всю ширину рамки
  (210 − 20 − 10 = 180), альбомная А4 тоже допустима.

Поля (координаты от левого нижнего угла надписи, мм; наименования полей ISO 7200, разд. 4):

| Поле (`Iso7200Field`) | ISO 7200 | x | y | Значение (`Iso7200Data`) |
|---|---|---|---|---|
| `Department` | Responsible department | 0…30 | 27…36 | `department` |
| `Creator` | Created by | 30…60 | 27…36 | `creator` |
| `Projection` | знак метода проекций (ISO 5456-2) | 0…15 | 18…27 | `projection` |
| `Scale` | масштаб (ISO 5455) | 15…30 | 18…27 | `scale` |
| `Approver` | Approved by | 30…60 | 18…27 | `approver` |
| `LegalOwner` | Legal owner | 0…60 | 0…18 | `legalOwner` |
| `DocumentType` | Document type | 60…120 | 27…36 | `documentType` |
| `Title` | Title | 60…120 | 0…27 | `title` (h до 7) |
| `DocumentStatus` | Document status | 120…180 | 27…36 | `documentStatus` |
| `Identification` | Identification number | 120…180 | 9…27 | `identification` (h до 7) |
| `Revision` | Revision index | 120…130 | 0…9 | `revision` |
| `IssueDate` | Date of issue | 130…156 | 0…9 | `issueDate` (ISO 8601) |
| `Language` | Language code | 156…166 | 0…9 | `language` (ISO 639) |
| `Sheet` | Sheet number | 166…180 | 0…9 | «лист/листов» |

Контур надписи — сплошная толстая, границы полей — сплошная тонкая. Наименование поля —
h = 2,5 в полосе 3,5 мм у верхнего края поля, слева; значение — ниже, h до 3,5 (наименование и
обозначение — до 7) с подбором по метрикам шрифта, как у формы 1 (шрифт ГОСТ 2.304 не
сжимается, высота уменьшается по ряду; не помещается и при 2,5 — `InvalidInput` с наименованием
поля), на 0,5 мм выше нижней линии поля (место нижних выносных элементов строчных букв).
Наименования полей — на языке документа (`iso7200FieldLabel`): код «ru…» — по-русски
(«Владелец», «Обозначение», «Дата выпуска», …), иначе — английские наименования ISO 7200.

**Знак метода проекций** (ISO 5456-2, рис. 4 и 5; ISO 128-30): `projectionSymbolGeometry(method,
center, h)` — усечённый конус в виде трапеции (узкий торец диаметром h слева, широкий 2h справа,
длина 2h) и его вид с торца — окружности диаметром h и 2h, зазор h, осевые штрихпунктирной тонкой
(горизонтальная через оба изображения, вертикальная через окружности, выход h/4); габарит 5h × 2h.
Первый угол (метод E, ЕСКД) — окружности справа от трапеции, третий угол (метод A) — слева. В
основной надписи h = 2,5 (знак 12,5 × 5 в поле 15 × 9). Пропорции записаны по памяти —
`docs/STANDARDS_VERIFICATION.md`.

Тест: `tests/drawing_v2/test_title_block_iso.cpp` — размеры рамки, надписи и полей по таблице
выше (сумма площадей полей = 180 × 36), типы линий, метки центрирования; тексты полей внутри
ячеек (линии знаков шрифта ГОСТ 2.304 не выходят из ячейки) на русском и английском, ошибки;
знак первого и третьего угла (диаметры, габарит, сторона окружностей); экспорт DXF (тексты,
окружности знака и линия рамки в мм) и PDF (MediaBox, угол рамки в пунктах; pdftotext — если
есть).

## Зоны поля чертежа — ГОСТ 2.104-2006, ISO 5457

`zoneGrid(sheet, frame, axis, letters, L = 50)` делит поле в пределах рамки на зоны:
по каждой стороне от оси симметрии `axis` откладываются поля длиной L (25…75 мм); число полей с
каждой стороны — round(половина листа / L), не меньше одного; последнее поле — до рамки. Колонки
нумеруются цифрами слева направо, строки — буквами сверху вниз (от угла, противоположного
основной надписи). При L = 50 число полей совпадает с табл. ISO 5457 (п. 3.5): A0 — 24 × 16,
A1 — 16 × 12, A2 — 12 × 8, A3 — 8 × 6, A4 — 6 × 4. Буквы: ISO — латинские без I и O, ЕСКД —
русские без Ё, З, Й, О, Х, Ъ, Ы, Ь (набор ГОСТ 2.316 для обозначений); строк больше, чем букв, —
удвоенные («AA»). `zoneOf(grid, p)` — зона точки («Б3»; точка вне рамки — ближайшая зона).

Пример — ЕСКД, А3 альбомная: рамка 20…415 × 5…292, ось рамки (217,5; 148,5); колонки
20 | 67,5 | 117,5 | 167,5 | 217,5 | 267,5 | 317,5 | 367,5 | 415 (8), строки сверху
292 | 248,5 | 198,5 | 148,5 | 98,5 | 48,5 | 5 (6: А…Е).

`zoneMarkingGeometry(grid, sheet, band, skipAxes)` и `addZoneMarking` — разметка на полях листа:
в полосе шириной `band` у края листа цифры сверху и снизу, буквы слева и справа (h = 3,5 по
центру клетки, по метрикам шрифта — до 2,5), штрихи на границах зон поперёк полосы — сплошные
тонкие, слой `FRAME`. В документе чертежа (`DrawingSettings::zones`, по умолчанию выключено):

| Оформление | Ось деления | Полоса | Буквы |
|---|---|---|---|
| ЕСКД | центр рамки | 5 мм (поля рамки сверху, справа, снизу; слева — у края листа, вне граф 19–23) | русские |
| ISO 7200 | оси листа (метки центрирования ISO 5457, п. 3.3) | 10 мм; штрихов на осях нет — там метки центрирования | латинские |

Зоны используются графой «Зона» спецификации ГОСТ 2.106 (`SPECIFICATION.md`). Правила ЕСКД для
разметки (длина зоны, буквы, место обозначений) записаны по ISO 5457 и практике —
`docs/STANDARDS_VERIFICATION.md`.

## Ограничения

- Основная надпись ISO 7200 — одна и та же на всех листах (сокращённой надписи последующих
  листов нет); поле «Supplementary title» не реализовано.
- Сплайн не реализован (нужен для линий обрыва и кривых видов — будет вместе с HLR).
- Многострочный текст и перенос строк не поддерживаются; наименование — одна строка.
- Шрифт ГОСТ 2.304 тип Б — собственный однолинейный (`EXPORT.md`); ширины знаков записаны по
  памяти и требуют сверки с табл. 4–6 стандарта (`docs/STANDARDS_VERIFICATION.md`). Шрифт
  типа А (d = h/14) не реализован.
- Графы 24–26 (справочный номер, первичное применение, повёрнутое обозначение) не
  реализованы.
- Цвет при выводе в SVG/PDF — чёрный; цвет слоя используется только в DXF.

## Как тестировать

```bash
cmake -S . -B build-occt -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo -DBENDCORE_WITH_OCCT=ON \
  -DBENDCORE_OCCT_DIR=/home/user/bendcore/third_party/occt-install
cmake --build build-occt --target test_drawing_v2
ctest --test-dir build-occt -R drawing_v2 --output-on-failure
```

Тесты модели: `tests/drawing_v2/test_sheet_linetypes.cpp` (таблицы ГОСТ 2.301 и ISO 216,
правило деления пополам ISO 216, диапазоны ГОСТ 2.303), `test_model.cpp` (проверки
примитивов, штриховка против аналитики: квадрат 10×10 при шаге 2 — 5 линий длиной 10;
квадрат с отверстием — сумма длин · шаг ≈ площадь 1500), `test_title_block.cpp` (размеры
рамки, надписи и граф по таблице выше, линии и их тип, размещение текстов, ошибки),
`test_stroke_font.cpp` (основная надпись шрифтом ГОСТ без сжатия, линии текста не пересекают
линии граф), `test_sheet_multiples_zones.cpp` (все 19 кратных форматов табл. 2 в обеих
ориентациях — ГОСТ и ISO 5457 — против таблицы, переписанной из стандарта; список кратностей;
рамка, основная надпись и графы 19–23 на каждом кратном формате ЕСКД и ISO, метки
центрирования; сетка зон А3 против ручного расчёта, число полей ISO A0…A4 по табл. ISO 5457,
буквы без I/O и удвоенные, ошибки; разметка ISO A3 — 28 обозначений, 20 штрихов вне осей, DXF —
текст «3» в x = 135, «C» в середине третьей строки, штрихи x = 110).
