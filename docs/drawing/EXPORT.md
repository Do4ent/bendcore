# Экспорт чертежа: DXF, SVG, PDF

API — `include/bendcore/drawing_v2/export.hpp`. Писатели возвращают буфер
(`Result<std::string>`); `saveToFile(path, bytes)` записывает его в файл. Все три формата —
собственные писатели без сторонних библиотек (MIT-совместимо).

Общее для всех форматов: 1 единица = 1 мм листа; штриховка выводится отрезками, найденными
`hatchSegments`; дуга — против часовой стрелки от `startDeg` до `endDeg`. Текст выводится
шрифтом, выбранным у листа (`Drawing::textFont()`): однолинейным шрифтом типа Б ГОСТ 2.304
(линиями, см. ниже) или шрифтом TrueType (`TEXT` / `<text>` / встроенный шрифт PDF).

## Шрифт ГОСТ 2.304

Встроенный однолинейный (stroke) шрифт типа Б ГОСТ 2.304-81 — прямой и с наклоном 75°
(`include/bendcore/drawing_v2/stroke_font.hpp`, `src/drawing_v2/stroke_font.cpp`,
`gostStrokeFont()`). Шрифт нарисован в проекте (свой код, лицензия MIT проекта), в
репозитории нет файлов шрифтов.

Геометрия — по сетке ГОСТ 2.304 с шагом d = h/10 (толщина линии шрифта типа Б):

| Параметр (ГОСТ 2.304, табл. 2, тип Б) | В долях d | В коде |
|---|---|---|
| Высота прописных букв и цифр h | 10 | `kCapHeight` |
| Высота строчных букв c | 7 | `kLowerHeight` |
| Выносные элементы строчных (р, у, ф — вниз; б, ф — вверх до h) | 3 | `kDescender` |
| Расстояние между буквами a | 2 | `kLetterSpacing` |
| Минимальное расстояние между словами e | 6 | `kWordSpacing` (пробел = e − 2a) |
| Минимальный шаг строк b | 17 | `kLineSpacing` |
| Толщина линии d | h/10 | `strokeWidth(h)` |

Ширины знаков, d (ГОСТ 2.304, табл. 4 — кириллица и цифры; латиница — по табл. 6; записаны по
памяти, `docs/STANDARDS_VERIFICATION.md`):

| Ширина | Прописные | Строчные | Цифры |
|---|---|---|---|
| 3 | | | 1 |
| 4 | | с | |
| 5 | Г Е З С | а б в г д е з и й к л н о п р у х ц ч ь э я | 0 2 3 5 6 7 8 9 |
| 6 | Б В И Й К Л Н О П Р Т У Ц Ч Ь Э Я | м ъ ы ю | 4 |
| 7 | А Д М Х Ы Ю | ж т ф ш щ | |
| 8 | Ж Ф Ш Щ Ъ | | |

Ширина и высота знака измеряются по оси линии (оси линий укладываются в клетку ширины ×
высоты; толщина d добавляется по d/2 с каждой стороны). Нижние выносные элементы Д, Ц, Щ, д,
ц, щ — 2d. Наклон 75° — сдвиг x += y·tg 15° в системе строки (основание неподвижно), как и у
текста TrueType; выравнивание — по длине строки вдоль основания.

Состав: кириллица (33 + 33, с Ё ё), латиница (26 + 26), цифры, пробел и неразрывный пробел,
`. , : ; ! ? - – — − + = < > / \ | ( ) [ ] { } « » " ' ` ^ ~ _ * # % & $`, ′ ″ ° № ± × ·, знак
диаметра ⌀ (и Ø ø ∅ тем же начертанием), многоточие «…» (три точки с интервалом a, 7d — как
«...»), `@` (в стандарте нет; «а» в окружности, 7d — выбор проекта).

Греческие буквы (ГОСТ 2.304-81, греческий алфавит типа Б), нужные в машиностроительных
надписях: строчные α β γ δ ε η θ λ μ ν π ρ σ τ φ ω и прописные Δ Σ Ω — по той же сетке
(c = 7d; β γ η μ ρ φ — выносные элементы 3d вниз, β δ θ λ — вверх до h); ширины, d: ε — 4;
α β γ δ η θ λ μ ν ρ τ — 5; π σ — 6; φ ω Δ Ω — 7; Σ — 6. Ширины выбраны по похожим знакам
кириллицы и латиницы, начертание построено по сетке без рисунка стандарта — **требует сверки**
(`docs/STANDARDS_VERIFICATION.md`). Прописные Α Β Γ Ε Ζ Η Ι Κ Μ Ν Ο Π Ρ Τ Υ Φ Χ и строчные
ο κ χ — начертанием совпадающих латинских и кириллических букв; знак микро µ (U+00B5) — как μ,
ом Ω (U+2126) — как Ω, приращение ∆ (U+2206) — как Δ.

Нет: остальных греческих букв, римских цифр отдельными знаками (пишутся латиницей), ≈ ≤ ≥ и
других математических знаков. Знак вне шрифта — ошибка `Unsupported` с кодом знака
(`GostStrokeFont::layout`); метрики для такого знака считают ширину 6d.

Метрики (`TextMetrics`): `textWidthMm` = Σ ширин + a·(n − 1), в мм при высоте h;
`minWidthFactor() = 1` — шрифт ГОСТ при подгонке в графу не сжимается, вместо этого высота
уменьшается по ряду ГОСТ 2.304 (основная надпись `DRAWING_MODEL.md`, спецификация
`SPECIFICATION.md`). Шрифт TrueType (`TrueTypeFont`) — тоже `TextMetrics`, сжимается до 0,6.

Вывод по форматам (лист с `TextFont::Gost2304`):

| Формат | Линии знаков | Исходный текст (поиск, копирование) |
|---|---|---|
| DXF | `LWPOLYLINE` на слое текста, тип `Continuous`, толщина 370 — ближайшая к h/10 (2,5 → 25; 3,5 → 35; 5 → 50; 7 → 70) | `TEXT` с группой 60 = 1 (невидимый); `DxfOptions::sourceText = false` — не писать |
| SVG | `<g class="text" data-text="…">` с одним `<path>` (`stroke-width` = h/10, `stroke-linecap/linejoin="round"`, `data-linetype="gost2304"`) | прозрачный `<text>` (`fill-opacity="0"`, `textLength` = длина строки) в той же группе; `SvgOptions::sourceText` |
| PDF | контуры `m … l S`, `w` = h/10 в пунктах, `[] 0 d 1 J` (круглые концы) | невидимый текст `3 Tr` шрифтом `PdfOptions::font` (если задан и содержит все знаки строки), коэффициент ширины в `Tm` подогнан к длине линий; без `font` PDF не содержит шрифтов |

Выбор шрифта документа — `DrawingSettings::textFont` и `SpecificationSettings::textFont`
(по умолчанию `gost2304`, сохраняются в файлах `"textFont": "gost2304" | "truetype"`); лист,
созданный напрямую `Drawing::create`, — `TrueType`. В WASM — `setSettings({textFont})`
(`src/wasm/bendcore_drawing_api.mjs`); спецификация сессии следует шрифту чертежа.

Пример листа: `docs/drawing/examples/assembly_unit_gost2304.png` (сборочный чертёж узла из
`test_drawing_document_assembly`), образец всех знаков — `gost2304_specimen.png`
(`DrawingV2StrokeFont.SpecimenSheet`).

## DXF — AutoCAD R2000 (AC1015), ASCII

Почему R2000: в R12 нет `LWPOLYLINE` и толщин линий (группа 370); R2007+ требует UTF-8 и
заметно больше обязательных объектов. R2000 читается всеми распространёнными программами.

Состав файла: `HEADER` (`$ACADVER AC1015`, `$DWGCODEPAGE ANSI_1251`, `$INSUNITS 4` — мм,
`$MEASUREMENT 1`, `$EXTMIN/$EXTMAX`, `$LIMMIN/$LIMMAX` — размер листа, `$LTSCALE 1`,
`$HANDSEED`), `CLASSES` (пустая), `TABLES` — `VPORT` (*Active на весь лист), `LTYPE`
(ByBlock, ByLayer, Continuous и шаблоны ГОСТ: `GOST_DASHED`, `GOST_DASHDOT_THIN`,
`GOST_DASHDOT_THICK`, `GOST_DASHDOTDOT`, элементы 49 в мм), `LAYER` (цвет 62), `STYLE`
(`GOST_UPRIGHT`, `GOST_SLANT` с наклоном 15°, шрифт `DejaVuSans.ttf`), `VIEW`, `UCS`,
`APPID`, `DIMSTYLE`, `BLOCK_RECORD`; `BLOCKS` (*Model_Space, *Paper_Space); `ENTITIES`;
`OBJECTS` (корневой словарь и `ACAD_GROUP`). У каждого объекта — дескриптор (5) и владелец
(330).

Сущности: `SOLID` (залитый многоугольник `SolidFill` — веером треугольников, точка 13 = 12), `LINE`, `ARC`, `CIRCLE`, `LWPOLYLINE` (флаг 128 — непрерывный шаблон по всей
полилинии), `TEXT` (40 — высота прописных, 41 — коэффициент ширины, 50 — поворот,
51 — наклон 15°, 72/73 и точка 11 — выравнивание). Каждая сущность несёт слой (8), тип
линии (6) и толщину (370) — ближайшее значение из стандартного набора AutoCAD
(`dxfLineweight`: 0,25 → 25; 0,333 → 35; 0,75 → 70); точная толщина остаётся в SVG/PDF.

Кириллица. В DXF до R2007 строки — однобайтовые в кодовой странице `$DWGCODEPAGE`; любой
символ Unicode из BMP записывается последовательностью `\U+XXXX` (так пишет сам AutoCAD
R2000–R2004). Писатель выводит чистый ASCII: не-ASCII символы — `\U+XXXX`,
`$DWGCODEPAGE = ANSI_1251` для программ, которые смотрят на кодовую страницу. Плюсы: файл
не зависит от кодовой страницы читателя, работают и символы вне cp1251 (Ø, °, ±, №).
Символы вне BMP (> U+FFFF) так не записываются — ошибка `Unsupported`.

## SVG 1.1

`width="<W>mm" height="<H>mm" viewBox="0 0 W H"` — 1 единица пользователя = 1 мм, печать
без масштабирования даёт 1:1. Ось Y переворачивается координатами (y_svg = H − y), без
`transform` на группах, поэтому числа в файле прямо сверяются с моделью. Слой → `<g
id="layer-NAME">`. Линии: `stroke-width` = толщина ГОСТ в мм, `stroke-dasharray` из шаблона
(`renderDashArray`), `stroke-linecap="butt"`; атрибут `data-linetype` — имя типа линии.
Дуга — `path` с командой `A` (sweep-flag 0 = против часовой стрелки на листе). Текст —
`<text>` с `font-size = h / (capHeight/unitsPerEm)` (по шрифту из `SvgOptions::font` или
`capHeightRatio`, 0,729 для DejaVu Sans), `text-anchor` для выравнивания по горизонтали,
`transform="translate(x y) rotate(-α) translate(0 dy) skewX(-15) scale(k 1)"`. Шрифт в SVG
не встраивается — указывается `font-family="DejaVu Sans"`; при отсутствии шрифта у
просмотрщика ширина строк будет другой (высота прописных — тоже, если у замены другая
пропорция).

## PDF 1.4, векторный

- `writePdf` — одна страница; `writePdfPages` — несколько листов в одном файле (размер
  страницы — по листу, шрифт и `ToUnicode` общие).
- Залитый многоугольник `SolidFill` — `m … l h f` (цвет заливки 0 g).
- Страница: `MediaBox [0 0 W·72/25,4 H·72/25,4]`: А4 = 595,2756 × 841,8898 pt,
  А3 альбомный = 1190,5512 × 841,8898 pt.
- Координаты содержимого — сразу в пунктах (без `cm`), 4 знака после точки; начало — левый
  нижний угол, как в модели.
- Линии: `w` — толщина ГОСТ, `d` — шаблон штрихов в пунктах, `J 0` (без выступа),
  `j 1`. Окружность и дуга — кубические Безье по ≤ 90° (`k = 4/3·tan(θ/4)`, отклонение от
  окружности ≤ 2,7·10⁻⁴ r).
- Таблица `xref` — записи ровно по 20 байт, смещения указывают на `n 0 obj`; `/Length`
  потоков точный; сжатия нет (zlib в проекте не используется).
- Текст: шрифт TrueType встраивается целиком (`FontFile2`, `/Length1` = размер файла) как
  `CIDFontType2` + `Type0` с кодировкой `Identity-H` (код = индекс глифа,
  `CIDToGIDMap /Identity`), массив ширин `W` для использованных глифов, карта `ToUnicode`
  (поиск и копирование текста, `pdftotext`). Кегль = h / (capHeight/unitsPerEm), матрица
  `Tm = [k·cos k·sin (t·cos − sin) (t·sin + cos) x y]`, где t = tan 15° — наклон 75°,
  k — коэффициент ширины. Выравнивание по ширине строки из `hmtx` (без кернинга).
- Символ, которого нет в шрифте, — ошибка `Unsupported`; текст без шрифта — `InvalidInput`.
- `/Info /Title` — UTF-16BE.

Размер: шрифт встраивается целиком (DejaVu Sans — 742 КБ), PDF с текстом ≈ 770 КБ.
Подмножество шрифта (subset) не реализовано.

### Шрифты и лицензии

Шрифт не хранится в репозитории — берётся из системы (`findSystemFont`): переменная
`BENDCORE_DRAWING_FONT`, затем стандартные пути DejaVu Sans и Liberation Sans
(`defaultFontCandidates`).

| Шрифт | Лицензия | Встраивание |
|---|---|---|
| DejaVu Sans | Bitstream Vera Fonts License (+ public domain для изменений DejaVu) — пермиссивная | разрешено, `fsType = 0` |
| Liberation Sans | SIL Open Font License 1.1 | разрешено |

Шрифт с `OS/2 fsType` = Restricted License отвергается (`Unsupported`). Поддерживаются
только шрифты с контурами TrueType (`glyf`); OpenType-CFF (`.otf`) — ошибка.

## Как проверяется

`ctest --test-dir build-occt -R drawing_v2 --output-on-failure`; файлы пишутся в
`build-occt/drawing_v2_out/` (`sample_a3.dxf/.svg/.pdf`, `sample_a4.pdf`).

- DXF (`test_dxf.cpp`): файл читается собственным разборщиком групповых кодов в тестах
  (`src/dxf_reader.cpp` не годится — он не разбирает координаты); проверяются порядок
  секций, переменные HEADER, уникальность дескрипторов и `$HANDSEED`, шаблоны LTYPE, слои,
  стили, число и координаты LINE/ARC/CIRCLE/LWPOLYLINE/TEXT против модели, слой/тип/толщина
  каждой линии, тексты основной надписи после декодирования `\U+XXXX`. Если задана
  переменная `BENDCORE_PYTHON_EZDXF` (python с пакетом ezdxf, MIT), файл дополнительно
  читается ezdxf: версия AC1015, `audit()` без ошибок, число сущностей совпадает,
  `$INSUNITS = 4`, кириллица декодируется `ezdxf.decode_dxf_unicode`. Проверено с ezdxf 1.4.5.
- SVG (`test_svg.cpp`): атрибуты `svg`, координаты отрезков/окружности/дуги/полилинии с
  переворотом Y, толщины и `stroke-dasharray` по ГОСТ, кегль по метрикам шрифта, тексты;
  `xmllint --noout`, если установлен.
- PDF (`test_pdf.cpp`): разбор xref (каждое смещение указывает на объект), `/Length`
  потоков, MediaBox А3/А4, координаты отрезков и рамки в пунктах, толщины и шаблоны,
  точки Безье окружности на окружности, матрица текста (наклон 15°), кегль, встроенный
  шрифт байт в байт, ширины W, ToUnicode; программы poppler, если установлены: `pdfinfo`
  (размер страницы «A3», заголовок), `pdffonts` (CID TrueType, Identity-H, встроен, есть
  ToUnicode), `pdftotext` (кириллические тексты основной надписи).
- Шрифт (`test_font.cpp`): метрики DejaVu Sans против значений fontTools (unitsPerEm 2048,
  индексы и ширины глифов H, А, Я, ж, пробела, высота прописных 1493); отказ для
  шрифта с запретом встраивания.
- Шрифт ГОСТ 2.304 (`test_stroke_font.cpp`, файлы `gost_font_a3.*`, `gost_font_specimen.*`):
  ширины знаков против таблицы ширин (ось линий в клетке [0, w], крайние линии не дальше
  0,75d от границ), высоты прописных и цифр 10d, строчных 7d, выносные элементы 2d/3d;
  интервалы a = 2d и e = 6d по длине строки; наклон левой вертикали «Н» — 75° (прямой — 90°);
  поворот и выравнивание; знак вне шрифта (≈) — `Unsupported` с кодом; «…» — ширина и точки
  как у «...»; греческие буквы — высоты по сетке (Δ Σ Ω — 10d, α ε π σ ω ν τ — 7d, выносные 3d),
  знаки заполняют клетку; строка «α = 20°, Δt = 0,1…0,3 мм, σт = 355 МПа, μ = 0,15, ω, π, @»
  раскладывается; образец шрифта — со строкой греческих букв; основная надпись формы 1 —
  ни одного сжатого текста, высоты граф по длине строк, ни одна линия текста не пересекает
  линии граф (> 10 000 пар отрезков); слишком длинная фамилия — ошибка, а не сжатие. DXF:
  число `LWPOLYLINE` на слое `TITLE` = числу линий знаков, координаты линии «Т», толщины 25/35/
  50/70, все `TEXT` невидимы; ezdxf — `audit()` без ошибок, те же числа, атрибут `invisible`.
  SVG — группы по текстам, `stroke-width` 0,7 для h = 7, координаты, `xmllint`. PDF — без шрифта
  нет `FontFile2` и `BT`, `1 J`, толщина 1,9843 pt для h = 7, начало линии «Т» в пунктах; со
  шрифтом — `3 Tr`, `pdftotext` находит обозначение, наименование, «ООО «Бенд»», «⌀20».

Не проверено: открытие файлов в AutoCAD, Компас, Acrobat — этих программ в среде
разработки нет; отображение невидимого `TEXT` (группа 60) и полилиний шрифта в AutoCAD/
КОМПАС. Объекты LAYOUT в DXF не пишутся (ezdxf создаёт их при чтении; AutoCAD
обычно восстанавливает их сам, но это не проверялось).
