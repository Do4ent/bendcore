# Библиотека стандартного крепежа `bendcore_fasteners`

Фаза 3, п. 5 `docs/ROADMAP_GENERAL_CAD.md` (раздел 2.2, «Библиотека»): параметрические
твердотельные модели стандартного крепежа ГОСТ/ISO, таблицы размеров, свойства для BOM и
спецификации, именованные грани для сопряжений, постановка пакета крепежа в отверстия.

- Код: `include/bendcore/assembly_v2/fasteners.hpp`, `src/assembly_v2/fasteners/`
  (`tables.cpp` — таблицы, `models.cpp` — модели OCCT, `placement.cpp` — отверстия и постановка).
- Сборка: `cmake/fasteners.cmake`, цель `bendcore_fasteners` (зависит от `bendcore_assembly_document`).
- Тесты: `tests/assembly_v2/test_fasteners_models.cpp`, `test_fasteners_placement.cpp`.
- Пространство имён `bendcore::assembly_v2::fasteners`; функции возвращают `kernel::Result`.

## 1. Статус сверки таблиц — ВАЖНО

**Все таблицы требуют сверки с официальными изданиями стандартов.** При составлении не было
доступа ни к текстам стандартов, ни к открытым справочным сайтам (сеть среды разработки
закрыта: запросы к en.wikipedia.org, fasteners.eu, engineeringtoolbox.com, docs.cntd.ru,
boltdepot.com отклонены прокси), поэтому URL-источников нет. Значения записаны по памяти.
`tableInfo(standard)` возвращает источник, `verified = false` и текст «требует сверки с
официальным изданием». Ряды ограничены размерами, в которых автор уверен; размер вне ряда —
`Unsupported` со списком доступного ряда, экстраполяции нет.

Порядок сверки: сравнить каждую строку с официальным изданием (ГОСТ — действующая редакция с
изменениями; ISO — текущая редакция), исправить `tables.cpp`, тесты с табличными числами
(`test_fasteners_models.cpp`), установить `verified = true` для сверенной таблицы и записать
редакцию стандарта в `TableInfo::source`.

## 2. API

```cpp
#include <bendcore/assembly_v2/fasteners.hpp>
using namespace bendcore::assembly_v2;
using namespace bendcore::assembly_v2::fasteners;

auto bolt = makeFastener({FastenerStandard::Gost7798, 10, 40}).value();
bolt.properties.designation;   // "Болт М10×40 ГОСТ 7798-70"
bolt.thread;                   // M10, P = 1,5, d3, b = 26
auto boltDef = addFastenerPart(doc, bolt).value();
auto washerDef = addFastenerPart(doc, makeFastener({FastenerStandard::Gost11371, 10}).value()).value();
auto nutDef = addFastenerPart(doc, makeFastener({FastenerStandard::Gost5915, 10}).value()).value();

auto sites = findHoleSites(doc, {plateOcc}, Vec3(0, 0, -1), 5.5).value();  // Ø11, сверху вниз
auto placed = insertFastenerStacks(doc, {boltDef, {washerDef}, {washerDef}, nutDef}, sites).value();
doc.solve();   // сопряжения уже выполнены; 1 степень свободы (поворот) у каждой детали
```

| Функция | Назначение |
|---|---|
| `coarsePitch`, `hexBoltRow`, `socketScrewRow`, `hexNutRow`, `washerRow`, `springWasherRow`, `pinRow` | строки таблиц; `InvalidInput` — стандарт другого вида, `Unsupported` — нет размера |
| `tableInfo` | источник, статус сверки, ряд |
| `makeFastener(FastenerSpec{standard, size, length})` | модель, карта граней, резьба, свойства, размеры |
| `toPartData`, `toPartProperties`, `addFastenerPart` | деталь документа сборки |
| `findHoleSites` | отверстия детали с плоскостями входа и выхода |
| `insertFastenerStacks` | вхождения и сопряжения пакета для набора отверстий |

## 3. Модели

Ось — Z. Резьба условная: стержень номинального диаметра d, отверстие гайки — тоже d;
шаг, d3/D1, длина резьбы и обозначение «M10» — в `ThreadAttributes` для чертежа.

| Изделие | Построение | СК |
|---|---|---|
| Болт | головка: шестигранная призма ∩ тело вращения с фаской 30° сверху; стержень с фаской 45° от d3 до d на конце; объединение | опора головки z = 0, головка [0, k], стержень [−l, 0] |
| Винт ISO 4762 | цилиндр dk × k с фаской кромки 45° × 0,1·d; стержень как у болта; шестигранное углубление s глубиной t (плоское дно) | как у болта |
| Гайка | шестигранная призма ∩ кольцо вращения с фасками 30° на обоих торцах, отверстие d | [0, m] |
| Шайба плоская | кольцо d1–d2 толщиной h | [0, h] |
| Шайба пружинная | кольцо d1 – d1 + 2b толщиной s с радиальным разрезом шириной s по +X | [0, s] |
| Штифт | цилиндр d длиной l с фасками 45° × c на обоих торцах | [0, l] |

**Условные элементы (не табличные):** фаска 30° головки и гайки начинается на окружности
0,95·s; фаска кромки головки винта 0,1·d; ширина разреза пружинной шайбы = s, развод концов
и винтовая форма не моделируются; нет подголовочного галтеля, опорной шайбы головки (dw),
конического дна углубления винта и зенковок гайки. Модель — геометрия номинальных размеров.

Тело проходит `ShapeUpgrade_UnifySameDomain` и `BRepCheck_Analyzer`; результат — одно тело.
Масса = V·10⁻⁹·7850 кг (`BRepGProp`), у пружинной шайбы материал «Сталь 65Г».

## 4. Свойства для BOM и спецификации

`FastenerProperties`: `name` («Болт», «Гайка», «Шайба», «Шайба пружинная», «Винт», «Штифт»),
`designation` по своему стандарту, `equivalentDesignation` — обозначение по стандарту-соответствию
(ГОСТ 7798 ↔ ISO 4014/4017, ГОСТ 11738 ↔ ISO 4762, ГОСТ 5915 ↔ ISO 4032, ГОСТ 11371 ↔ ISO 7089,
ГОСТ 3128 ↔ ISO 2338), только если его таблица даёт те же размеры этого типоразмера (иначе
пусто: изделия не взаимозаменяемы), `section` = «Стандартные изделия», материал, плотность,
объём, масса.

| Изделие | ГОСТ | ISO |
|---|---|---|
| Болт | Болт М10×40 ГОСТ 7798-70 | Болт ISO 4014 - M10 x 40 |
| Винт | Винт М8×30 ГОСТ 11738-84 | Винт ISO 4762 - M8 x 30 |
| Гайка | Гайка М10 ГОСТ 5915-70 | Гайка ISO 4032 - M10 |
| Шайба | Шайба 10 ГОСТ 11371-78 | Шайба ISO 7089 - 10 |
| Пружинная шайба | Шайба 10 65Г ГОСТ 6402-70 | — |
| Штифт | Штифт 8 m6×40 ГОСТ 3128-70 | Штифт ISO 2338 - 8 m6 x 40 |

Обозначения сокращены: класс прочности, покрытие, исполнение и поле допуска резьбы не пишутся.
По ГОСТ 2.106 стандартные изделия записываются в графу «Наименование» полным обозначением,
графа «Обозначение» пустая — так заполняет `toPartProperties` (`PartProperties::name` =
обозначение, `designation` пусто), поэтому `flatBom` показывает «Болт М10×40 ГОСТ 7798-70».

## 5. Именованные грани и постановка в отверстия

Карта элементов (`modeling::buildNamedShape`, признак `Fastener`) строится по геометрии готового
тела; имена — `Fastener:<роль>`:

| Роль | Болт/винт | Гайка | Шайбы | Штифт |
|---|---|---|---|---|
| `Bearing` | опорная поверхность головки (z = 0, нормаль −Z) | торец z = 0 | торец z = 0 | — |
| `Top` | торец головки | торец z = m | торец z = h | — |
| `Shank` | стержень (ось) | — | — | цилиндр |
| `Bore` | — | отверстие | отверстие | — |
| прочие | `Tip`, `TipChamfer`, `HeadChamfer`, `Flat1…6`, винт: `Outer`, `Socket1…6`, `SocketBottom` | `Flat1…6`, `BearingChamfer`, `TopChamfer` | `Outer`, пружинная: `Slot1`, `Slot2` | `End1`, `End2`, `EndChamfer1/2` |

`Flat`/`Socket` нумеруются по углу наружной нормали от +X, `Slot` и `End` — по координате.

**`findHoleSites(doc, path, insertion, radius)`**: цилиндрические грани детали радиуса `radius`
(допуск `tol·max(1, r)`), ось параллельна `insertion`, наружная нормаль грани направлена к оси
(отверстие, а не вал). Соосные грани объединяются. Смежные плоские грани, перпендикулярные
оси, упорядочиваются по положению вдоль `insertion`: первая (с нормалью против `insertion`) —
вход, последняя (с нормалью по `insertion`) — выход; у глухого отверстия выхода нет (дно
смотрит навстречу крепежу). Отверстия без плоскости входа пропускаются.

**`insertFastenerStacks(doc, stack, sites)`** на каждое отверстие: шайбы под головку ставятся от
плоскости входа, болт — опорой на последнюю; шайбы под гайку и гайка — от плоскости выхода.
Для каждой детали: поворот, переводящий нормаль `Bearing` в −(нормаль опоры), и перенос точки
оси на `Bearing` в точку оси отверстия на опоре; сопряжения `Concentric(Shank|Bore, отверстие)`
и `Coincident(Bearing, опора, AntiAligned)`. Положения вставки уже удовлетворяют сопряжениям;
каждая деталь сохраняет одну степень свободы (поворот вокруг оси). `grip` — от опоры головки
до торца гайки (без гайки — до плоскости выхода/последней шайбы, у глухого отверстия — до
плоскости входа), `protrusion` — выступ конца стержня за эту плоскость (глухое отверстие —
глубина захода). Ошибки (документ не меняется — работа идёт на копии): нет граней крепежа у
определения, ось не перпендикулярна входу/выходу, гайка у глухого отверстия, стержень короче
пакета.

**Правило пересечений условной резьбы.** Отверстие гайки моделируется номинальным диаметром
стержня, поэтому резьбовая пара — касание по цилиндру (нулевой объём), а не пересечение. Если
отверстие гайки будет моделироваться по D1, пара «болт–гайка» даст объём кольца
`π/4·(d² − D1²)·m` — его нужно исключать как резьбовое соединение.

## 6. Ограничения

- Таблицы не сверены (раздел 1). Ряд предпочтительных длин не проверяется — принимается любая
  длина, при которой модель строится (ISO 4014: l > b, иначе ошибка с указанием ISO 4017).
- Только крупный шаг; мелкий шаг, классы прочности, покрытия, исполнения по ГОСТ не задаются.
- Пакет ставится в отверстия с плоскими торцами, перпендикулярными оси; зенковки и цековки
  определяются как вход, если их дно — плоскость, перпендикулярная оси, смежная с отверстием.
- Штифты в `insertFastenerStacks` не используются (у штифта нет опорной поверхности); их ставят
  сопряжениями `Shank`/`End1` вручную.

## 7. Как тестировать

```bash
cmake --build build-occt --target test_fasteners_models test_fasteners_placement
ctest --test-dir build-occt -R fasteners --output-on-failure
```
