# Операции детали

Библиотека `bendcore_modeling_features` (STATIC, `cmake/modeling_features.cmake`), пространство
имён `bendcore::modeling`, заголовок `include/bendcore/modeling/features.hpp`, исходники
`src/modeling/features/`. Линкует `bendcore_kernel` и `bendcore_kernel_healing`; все булевы
операции идут через `kernel::booleanOp` (лестница нечёткого допуска, проверка результата,
`SimplifyResult`, см. `docs/kernel/GEOMETRY_HEALING.md`).

Операции — чистые функции: вход (профиль, целевое тело, параметры, ссылки на грани/рёбра как
`TopoDS_Shape`) → `Result<FeatureResult>`. Исключения OCCT перехватываются и возвращаются как
`ErrorCode::OperationFailed`; неверный вход — `InvalidInput`; неподдержанное сочетание
параметров — `Unsupported`.

```cpp
struct FeatureResult {
    TopoDS_Shape shape;   // тело после операции
    TopoDS_Shape tool;    // инструмент (пусто у скругления, фаски, оболочки, уклона)
    opencascade::handle<BRepTools_History> history;
    std::vector<std::string> warnings;
};
struct Profile { TopoDS_Face face; gp_Ax3 placement; };
enum class FeatureMode { Boss, Cut };
```

## 1. Общие правила

### Профиль (`validateProfile`)

Грань не пуста; поверхность плоская (`GeomLib_IsPlanarSurface`, 1e-7); плоскость грани
параллельна `placement.Direction()` и проходит через `placement.Location()` (1e-6 мм); каждый
контур замкнут (каждая вершина использована чётное число раз невырожденными рёбрами); площадь
> 0; `BRepCheck_Analyzer` валиден. Отверстия в профиле — внутренние контуры грани. Нарушение →
`InvalidInput` с причиной («profile contour #1 is not closed…»).

Профиль никогда не входит в тело: операция заметает его копию (`BRepBuilderAPI_Transform`
с копированием), поэтому элементы профиля остаются ключами истории и не совпадают с элементами
результата.

### История

`BRepTools_History` от входов к `shape`. Шаги операции дают свои истории, они объединяются
`BRepTools_History::Merge` (история 1→2 ∘ 2→3).

* **Заметание** (`sweepHistory`, выдавливание и вращение): для каждого элемента профиля
  (грань, рёбра, вершины) начальный торец — `Modified`, конечный торец и боковые элементы —
  `Generated` (`BRepPrimAPI_MakePrism/MakeRevol::FirstShape(S)`, `LastShape(S)`,
  `Generated(S)`). Итог: грань профиля → нижний торец (Modified), верхний торец и тело
  (Generated); ребро профиля → боковая грань и рёбра торцов; вершина профиля → боковое ребро.
* **Булева операция** (`booleanWithHistory`). История — та, что вернуло ядро:
  `kernel::BooleanResult::history` = `BRepAlgoAPI_BuilderAlgo::History()` удачной попытки
  лестницы допусков, уже объединённая OCCT с историей `SimplifyResult`
  (`docs/kernel/GEOMETRY_HEALING.md`, раздел «История»). Геометрического восстановления нет.
  - части элемента входа в результате — `Modified` (грань коробки, получившая контур
    кармана; стенка инструмента, ставшая стенкой кармана; компланарные грани, слитые
    `UnifySameDomain`, — `Modified` в общую грань); тело аргумента — `Modified` в тело
    результата;
  - рёбра и вершины пересечения — `Generated` из граней (рёбер) входов, которые их породили;
  - элемент входа без образов в результате — `IsRemoved`.
  Записи переносятся только для элементов отслеживаемых входов (`trackArguments`,
  `trackTools`): вспомогательные тела (полупространство подрезки «до грани») в историю
  операции не попадают; грани результата, которые являются неизменёнными гранями или
  `Modified`-образами граней неотслеживаемых входов и не являются образами отслеживаемых,
  возвращаются в `untrackedImages` (из них выдавливание «до грани» берёт торец и пишет его
  `Generated` из грани профиля). Пустой результат (у ядра без истории) — все элементы
  отслеживаемых входов `Remove`.
* **Алгоритмы OCCT** (скругление, фаска, оболочка, уклон, тонкостенное): история
  `BRepTools_History(args, algo)` нормализуется: образ того же типа считается `Modified`
  (`BRepOffsetAPI_DraftAngle` возвращает изменённые грани в `Generated`), образ другого типа —
  `Generated`; элемент без `Modified`, которого нет в результате, — `Remove`
  (`BRepOffsetAPI_MakeThickSolid` удалённые грани не помечает).

Элемент входа, не упомянутый в истории и присутствующий в `shape`, перешёл без изменений.

### Применение инструмента (`applyTool`)

Boss: без целевого тела результат — сам инструмент; иначе `Fuse`. Cut: целевое тело
обязательно; `Cut`; если объём не изменился — `OperationFailed` («tool does not intersect»),
если тел не осталось — `OperationFailed`. Результат проверяется `BRepCheck_Analyzer`, объём
каждого тела > 0. Несколько тел в результате — предупреждение.

## 2. Выдавливание — `extrude(profile, target, ExtrudeParams)`

| Параметр | Значение |
|---|---|
| `mode` | Boss / Cut |
| `extent` | `Blind` (distance), `Symmetric` (distance всего, ±distance/2), `TwoSided` (distance вперёд, distance2 назад), `ThroughAll`, `ThroughAllBoth`, `UpToFace` (limit), `UpToSurface` (поверхность limit) |
| `reversed` | направление −`placement.Direction()` |
| `draftAngle`, `draftDirection` | уклон боковых граней [0, π/2), сужение (Inward) или расширение (Outward) от плоскости эскиза |
| `thin` | тонкостенное: толщина и сторона (Inside/Outside) |

Алгоритм:
1. Начало и длина вдоль направления: Blind — [0, d]; Symmetric — [−d/2, d/2]; TwoSided —
   [−d2, d]; ThroughAll — до дальней точки габарита цели + запас (1 + 1 % диагонали);
   ThroughAllBoth — от ближней до дальней; UpTo — за дальнюю точку грани-ограничителя.
2. `BRepPrimAPI_MakePrism` копии профиля, сдвинутой к началу.
3. Уклон: `BRepOffsetAPI_DraftAngle`, все боковые грани, нейтральная плоскость — плоскость
   эскиза, направление — направление выдавливания. Положительный угол OCCT наклоняет грань
   внутрь по ходу направления (проверено тестом объёма усечённой пирамиды).
4. Тонкостенное: `BRepOffsetAPI_MakeThickSolid::MakeThickSolidByJoin`, удаляются оба торца,
   смещение −t (Inside) или +t (Outside), стыки `GeomAbs_Intersection` (острые углы).
5. До грани/поверхности: тело «за ограничителем» — призма грани-ограничителя (UpToFace) или
   её поверхности, продолженной на 2·диагональ + длину (UpToSurface; плоскость — квадрат вокруг
   проекции эскиза, прочие поверхности — расширение диапазона параметров в непериодических
   направлениях в пределах поверхности) вдоль направления; инструмент обрезается `Cut`. Торец
   у ограничителя записывается как `Generated` из грани профиля. Если обрезанный инструмент
   доходит до конца длинной призмы — грань не перекрывает профиль → `InvalidInput`.
6. `applyTool`.

Ограничения: уклон только для односторонних условий (Blind, ThroughAll, UpTo*), не вместе с
тонкостенным (`Unsupported`); уклон строится для плоских и цилиндрических боковых граней,
на сплайновых `DraftAngle` может отказать (`OperationFailed`). Тонкостенное — только для
замкнутого профиля-грани (стенка вдоль всех контуров, включая отверстия), без торцов.
UpToFace/UpToSurface требуют, чтобы прямые вдоль направления пересекали ограничитель один
раз (иначе призма ограничителя самопересекается и вход отклоняется проверкой `booleanOp`).
Смещение от ограничителя не поддерживается.

## 3. Вращение — `revolve(profile, target, RevolveParams)`

`extent`: `Angle` (angle), `Full` (2π), `Symmetric` (angle всего, ±angle/2), `TwoSided`
(angle в положительную сторону, angle2 — в отрицательную); `reversed` меняет направление оси.

Проверки: ось лежит в плоскости эскиза (|cos| ≤ 1e-7, расстояние ≤ 1e-6 мм); профиль по одну
сторону от оси (33 точки на каждом ребре, знак расстояния в плоскости); суммарный угол
в (0, 2π]. Алгоритм: копия профиля поворачивается на начальный угол,
`BRepPrimAPI_MakeRevol` (полный оборот — конструктор без угла), история заметания, `applyTool`.

## 4. Отверстие — `hole(target, face, point, HoleParams, direction)`

Типы: Simple, Counterbore (`counterboreDiameter`, `counterboreDepth`), Countersink
(`countersinkDiameter` на грани, `countersinkAngle` при вершине, по умолчанию 90°).
Окончание: Blind (`depth` — глубина цилиндрической части от грани; `drillPoint` добавляет конус
сверла `drillPointAngle`, по умолчанию 118°, высота r/tg(59°)) или Through (до дальней точки тела
+ запас). Только геометрия; стандартные ряды ГОСТ/ISO и резьба не входят.

Проверки: грань принадлежит телу и плоская; точка в плоскости грани (1e-6) и внутри грани;
направление (по умолчанию — против внешней нормали грани с учётом её ориентации в теле)
направлено в материал; диаметры цековки/зенковки больше диаметра отверстия, их глубина меньше
глубины глухого отверстия.

Алгоритм: полупрофиль (радиус, глубина) — ломаная в плоскости, содержащей ось, →
`BRepBuilderAPI_MakeFace` → `BRepPrimAPI_MakeRevol` на 360° вокруг оси → `Cut`. История — как
у булевой операции; дополнительно `Generated(грань размещения)` → грани отверстия в
результате (стенка, дно, конус).

Ограничение: начальный торец инструмента перпендикулярен оси; при наклонной оси клин над
гранью не вырезается (как у сверла, начинающего с точки на грани).

## 5. Скругление и фаска

`fillet(target, edges, radius)` — `BRepFilletAPI_MakeFillet`, постоянный радиус, рёбра —
рёбра `target` (иначе `InvalidInput`). При неудаче (исключение, `!IsDone`, невалидный или
вырожденный результат) — `OperationFailed`, сообщение перечисляет неудачные рёбра: индексы во
входном списке и статус контура (`NbFaultyContours`, `FaultyContour`, `StripeStatus`); если
OCCT не назвал контуры — каждое ребро пробуется отдельно. `filletFailures` возвращает тот же
список как данные (`EdgeFailure{index, edge, reason}`); пустой список — все рёбра строятся.
История: `Generated(ребро)` → скругляющая грань, ребро — `Remove`, соседние грани — `Modified`.

`chamfer(target, edges, ChamferParams)` — `BRepFilletAPI_MakeChamfer`:
`EqualDistance` (`Add(d, E)`), `TwoDistances` (`Add(d1, d2, E, F)`: d1 по опорной грани F),
`DistanceAngle` (`AddDA(d, α, E, F)`: d по опорной грани, α — угол между опорной гранью и
фаской; второй катет d·tg α). Опорная грань — `referenceFace` (обязана примыкать к ребру) или
первая примыкающая грань (предупреждение).

## 6. Массивы и зеркало

`linearPattern` (1 или 2 направления, шаг, число; экземпляр 0 — исходный), `circularPattern`
(ось, число, угол; `equalSpacing`: при угле 2π шаг angle/count, иначе angle/(count−1);
без него angle — шаг), `mirrorFeature` (зеркальная копия инструмента относительно плоскости
`gp_Ax2`). Вход: тело с уже применённой исходной операцией и её `FeatureResult::tool`. Копии
(`BRepBuilderAPI_Transform` с копированием) применяются одной булевой операцией
`booleanOp(arguments = {target}, tools = копии)`. История: элементы копий — входы булевой
операции; дополнительно `Generated(элемент исходного инструмента)` → образы соответствующих
элементов копий в результате. `tool` — составное из копий. Вырез, копии которого не задевают
тело, — `OperationFailed`.

`mirrorBody(body, plane, merge)`: зеркальная копия тела; `merge` — `Fuse` (грани в плоскости
зеркала исчезают, совпадающие грани сливаются `SimplifyResult`), иначе составное из двух тел.
`Generated(элемент тела)` → образ его зеркального элемента.

## 7. Оболочка и уклон граней

`shell(body, removedFaces, thickness, Inward|Outward)` —
`BRepOffsetAPI_MakeThickSolid::MakeThickSolidByJoin` (смещение ∓t, `BRepOffset_Skin`,
`GeomAbs_Intersection`). Удаляемая грань в истории — `Modified` в торец стенок (так сообщает
OCCT). Слишком большая толщина → `OperationFailed`.

`draftFaces(body, faces, pullDirection, angle, neutralPlane)` — `BRepOffsetAPI_DraftAngle`;
angle > 0 наклоняет грань внутрь тела по мере движения вдоль `pullDirection`. Если грань не
принимается (`AddDone() == false`) — `OperationFailed` с её индексом.
