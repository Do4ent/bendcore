# Вспомогательная геометрия: плоскости, оси, точки, ЛСК

Фаза 1, п. 3 (вспомогательные плоскости и оси) `docs/ROADMAP_GENERAL_CAD.md`, раздел 2.1
«Вспомогательная геометрия». Заголовок `include/bendcore/modeling/reference_geometry.hpp`,
реализация `src/modeling/sketch/reference_geometry.cpp`, библиотека
`bendcore_modeling_sketch` (`cmake/modeling_sketch.cmake`), пространство имён
`bendcore::modeling`.

## Назначение

Построение опорных элементов из аналитических данных и из граней, рёбер и вершин формы:
на них размещаются эскизы (`SketchPlacement::fromPlane`), задаются оси вращения и массивов,
плоскости зеркала и сечений.

Представление — типы OCCT: плоскость `gp_Pln` (правая `gp_Ax3`, нормаль =
`Axis().Direction()`), ось `gp_Ax1`, точка `gp_Pnt`, ЛСК `gp_Ax3`. Подформы передаются
либо напрямую (`TopoDS_Face/Edge`, например после разрешения топологического имени), либо
индексом `kernel::TopologyIndex`. Все функции возвращают `kernel::Result<T>`; вырожденный
вход и подформа неподходящего вида — `InvalidInput` с причиной, исключения OCCT —
`OperationFailed`. `ReferenceTolerance{linear = 1e-7 мм, angular = 1e-9 рад}` задаёт пороги
вырожденности.

## API

### Плоскости

| Функция | Результат | Ошибки |
|---|---|---|
| `planeOffset(base, d)` | сдвиг на `d` вдоль нормали | `d` не конечно |
| `planeOffsetFromFace(face \| topo, i, d)` | плоскость грани с внешней нормалью, сдвиг наружу на `d` | грань не плоская, индекс |
| `planeAtAngle(base, axis, angle)` | поворот базовой плоскости на `angle` (правило правой руки вокруг `axis`) | ось не лежит в плоскости (не параллельна или вне её) |
| `planeThroughPoints(p1, p2, p3)` | начало `p1`, X к `p2`, нормаль `(p2−p1)×(p3−p1)` | совпадающие или коллинеарные точки |
| `planeTangentToCylinder(face \| topo, i, near)` | касательная вдоль образующей, ближайшей к `near`; нормаль — внешняя нормаль грани (для отверстия — к оси), X — ось цилиндра | грань не цилиндрическая, `near` на оси |
| `planeMidway(a, b)` (плоскости, грани, индексы) | посередине, нормаль первой | не параллельны, совпадают |
| `planeOfFace(face)` | плоскость грани с внешней нормалью | грань не плоская |

Внешняя нормаль плоской грани: нормаль поверхности `X × Y` (правая система), развёрнутая
для `TopAbs_REVERSED`. Для цилиндра нормаль поверхности направлена от оси (правая система
`gp_Cylinder`), для обратной грани — к оси.

### Оси

| Функция | Результат | Ошибки |
|---|---|---|
| `axisThroughPoints(p1, p2)` | от `p1` к `p2` | точки совпадают |
| `axisOfFace(face \| topo, i)` | ось цилиндрической или конической поверхности | другая поверхность |
| `axisOfEdge(edge \| topo, i)` | прямое ребро: начало в первой вершине, направление по ребру (с учётом ориентации) | ребро не прямое, вырожденное |
| `axisOfPlaneIntersection(a, b)` | линия пересечения, направление `na × nb`, начало — ближайшая к началу `a` точка линии | плоскости параллельны |

Точка линии пересечения: `x = pa + s·na + t·nb`, `na·x = na·pa ⇒ s = −t·c`,
`nb·x = nb·pb ⇒ t = nb·(pb − pa)/(1 − c²)`, `c = na·nb`.

### Точки

| Функция | Результат | Ошибки |
|---|---|---|
| `pointOfVertex(topo, i)` | координаты вершины | индекс |
| `pointOnEdge(edge \| topo, i, f)` | точка на доле `f ∈ [0, 1]` длины ребра от первой вершины (`GCPnts_AbscissaPoint`) | `f` вне диапазона, ребро без кривой |
| `pointCenterOfEdge(edge \| topo, i)` | центр окружности/дуги | ребро не круговое |
| `pointCentroidOfFace(face)` | центр тяжести площади (`BRepGProp`) | нулевая площадь |
| `pointAxisPlaneIntersection(axis, plane)` | пересечение оси и плоскости | ось параллельна плоскости |
| `pointProjectedOnPlane(p, plane)` | ортогональная проекция | — |

### Локальные системы координат

| Функция | Результат | Ошибки |
|---|---|---|
| `coordinateSystem(origin, z, x)` | правая ЛСК, X ортогонализуется к Z | X ∥ Z |
| `coordinateSystemFromPoints(o, onX, inXY)` | начало, точка на +X, точка в плоскости XY с y > 0 | вырожденные точки |
| `coordinateSystemOnPlane(plane, origin)` | оси плоскости (правые), начало — проекция `origin` | — |

## Пример

```cpp
#include <bendcore/modeling/reference_geometry.hpp>
#include <bendcore/modeling/sketch_profile.hpp>
using namespace bendcore::modeling;

auto topo = bendcore::kernel::TopologyIndex::build(shape).value();
auto mid  = planeMidway(topo, topFace, bottomFace);          // плоскость симметрии
auto tilt = planeAtAngle(mid.value(), axisOfEdge(topo, e).value(), M_PI / 6);
auto sketchPlacement = SketchPlacement::fromPlane(tilt.value());
```

## Ограничения

- Касательная плоскость к цилиндру строится к бесконечной поверхности: принадлежность линии
  касания границам грани не проверяется.
- `axisOfFace` — только цилиндр и конус; оси тора и поверхностей вращения не поддержаны
  (ошибка).
- Плоскости не ассоциативны сами по себе: пересчёт после изменения модели выполняет дерево
  операций, вызывая эти функции заново с подформами, разрешёнными топологическим именованием.

## Как тестировать

```bash
cmake --build build-occt --target test_modeling_sketch_reference
ctest --test-dir build-occt -R modeling_sketch_reference --output-on-failure
```

`tests/modeling/test_modeling_sketch_reference.cpp` сверяет с аналитикой: смещение от
плоскости и от нижней грани коробки (внешняя нормаль −Z); поворот XY вокруг оси X на 30°
(нормаль `(0, −sin, cos)`, ось лежит в плоскости); плоскость через (1,0,0), (0,1,0), (0,0,1)
(нормаль `(1,1,1)/√3`, расстояние до начала `1/√3`); касательная к цилиндру R5 под 60°
(начало на поверхности, ось на расстоянии R) и к отверстию в блоке (нормаль к оси);
средняя плоскость коробки z = 15; ось цилиндра и конуса; 12 прямых рёбер коробки; линия
пересечения x = 2 и y + z = 4; центры окружностей, диаметрально противоположная точка на
середине длины окружности, середина образующей; центр грани; пересечение оси (1,1,1) с z = 6;
ЛСК из направлений и из трёх точек. Каждая функция проверяется и на вырожденном входе.
