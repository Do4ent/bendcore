# Эталонные детали фазы 1

Критерий готовности фазы 1 (`docs/ROADMAP_GENERAL_CAD.md`): эталонные детали строятся с нуля
через документ детали, изменение любого размера эскиза перестраивает модель без потери
скруглений и отверстий в ≥ 95 % сценариев, файл сохраняется и открывается без расхождений.

Тест: `tests/modeling/test_modeling_document_reference_parts.cpp`
(`ctest --test-dir build-occt -R modeling_document_reference_parts --output-on-failure`).
Документ, операции и именование — `docs/modeling/PART_DOCUMENT.md`.

## Что проверяется для каждой детали

1. Деталь строится в `PartDocument` из эскизов (`Sketch`, размеры — выражения переменных
   документа) и операций; все узлы — `Ok`.
2. Объём — против аналитической формулы (относительная погрешность ≤ 1e-6).
3. Сценарии: переменные меняются (размеры эскиза и параметры операций), документ
   перестраивается; каждая ссылка «наблюдаемых» операций (скругление, фаска, отверстие,
   массив, зеркало, оболочка, уклон, эскиз на грани, вспомогательная плоскость) считается
   выжившей, если операция `Ok`, ссылка разрешена точно или по истории (не по сигнатуре) и
   объём совпал с формулой. Операция без ссылок (массив, зеркало) считается одной ссылкой.
   После сценариев — возврат к исходным размерам (объём совпадает бит в бит: пул результатов).
4. Сохранение → загрузка без кэша и с кэшем BRep: те же состояния, имена ссылок, объёмы
   (≤ 1e-9 отн.), имена всех граней и рёбер; загруженный документ остаётся параметрическим.
5. Отмена/повтор: транзакция с изменением размеров — `undo()` возвращает исходный объём
   точно (без пересчёта, `recomputed` пуст), `redo()` — изменённый; удаление последней
   операции и его отмена.

## Детали

Обозначения: `π` — пи; `fillet(r, L) = (1 − π/4)r²L`; `chamfer(d, L) = d²L/2`;
`ring(r, ρ) = (1 − π/4)r²·2π(ρ + r(10 − 3π)/(3(4 − π)))` — скругление вдоль окружности
радиуса ρ (Папп); `rc(d, R, ±) = πd²(R ∓ d/3)` — фаска 45° на наружной/внутренней кромке.

| # | Деталь | Построение | Объём | Сценарии |
|---|---|---|---|---|
| 1 | Кронштейн (L-профиль) | эскиз XZ (6 закреплённых точек) → выдавливание симметрично `Wd`; скругление внутреннего угла `r`; эскиз на полке с точкой → сквозное отверстие `d` | `(A·T + (B−T)·T)·Wd + fillet(r, Wd) − πd²/4·T` | A, B, T, Wd, r, положение и диаметр отверстия, все полки |
| 2 | Вал со шпоночным пазом | эскиз XZ ступенчатого контура → вращение вокруг X; вспомогательная плоскость `z = R1`; эскиз паза на ней → вырез глубиной `t`; фаски на обоих торцах | `πR1²L1 + πR2²(L−L1) − lk·S − rc(c,R1,+) − rc(c,R2,+)`, `S = (b/2)√(R1²−b²/4) + R1²·asin(b/2R1) − b(R1−t)` | R1 (плоскость паза следует), R2, L, L1, lk, b, t, c, положение паза |
| 3 | Фланец с отверстиями по окружности | эскиз XY: два круга → диск; эскиз на верхней грани → ступица; эскиз с точкой на диаметре `BC` → сквозное отверстие; круговой массив `N`; фаска наружной кромки | `π(D²−d0²)/4·T + π(Dh²−d0²)/4·h2 − N·πdh²/4·T − rc(c, D/2, +)` | D, T, BC, N = 6 → 8, dh, Dh, h2, c, d0 |
| 4 | Крышка со скруглениями | эскиз-прямоугольник с размерами-ограничениями → выдавливание; скругление 4 вертикальных рёбер; отверстие у угла + линейный массив 2×2 | `LWH − 4·fillet(r, H) − 4·πdh²/4·H` | L, W, H, r, отступ отверстий, диаметр, L и W вместе |
| 5 | Корпус с оболочкой | прямоугольник → выдавливание; оболочка внутрь `t` без верхней грани; эскиз на передней грани → глухое отверстие через стенку | `LWH − (L−2t)(W−2t)(H−t) − πd²/4·t` | L, W, H (выше и ниже), t, d |
| 6 | Плита с цековками | прямоугольник → выдавливание; эскиз с двумя точками → сквозные отверстия с цековкой; фаска кромки | `LWT − 2(πD²/4·k + πd²/4·(T−k)) − chamfer(c, L)` | L, W, T, d, D, глубина цековки, положение, c |
| 7 | Шкив с канавкой | эскиз XZ кольцевого сечения → вращение вокруг Z; эскиз канавки → вращение-вырез; скругления двух кромок дна канавки (вогнутые) | `π(R²−ri²)w − π(R²−(R−g)²)gw + 2·ring(rf, R−g)` | R, ri, w, g, gw, rf |
| 8 | Втулка с фасками | два круга → выдавливание; фаска наружной и внутренней верхних кромок | `π(R²−r²)h − rc(c1, R, +) − rc(c2, r, −)` | R, r, h, c1, c2 |
| 9 | Опора с зеркальной бобышкой | прямоугольник → плита; эскиз круга на верхней грани → бобышка; зеркало операции относительно YZ; скругление основания **зеркальной** бобышки (ссылка через имена инструмента) | `LWT + 2πrb²hb + ring(rf, rb)` | L, W, положение, радиус и высота бобышки, rf, T |
| 10 | Решётка с пазами | прямоугольник → плита; эскиз паза на верхней грани → вырез насквозь; линейный массив `n1 × n2`; фаска нижней кромки | `LWT − n1·n2·a·b·T − chamfer(c, L)` | L, n1 = 4 → 5, шаг, ширина паза, T, c, W |
| 11 | Литая бобышка с уклоном | квадрат → выдавливание; уклон 4 боковых граней от нижней (нейтральной) грани | `h/3·(a² + a'² + a·a')`, `a' = a − 2h·tg α` | a, h, α = 5° → 3°, 8° |

## Ограничения набора

- Сценарии меняют размеры и параметры, но не топологию эскиза (добавление/удаление
  сущностей): такие правки дают новые идентификаторы сущностей, ссылки на их грани
  разрешаются по сигнатуре (см. `PART_DOCUMENT.md`, «Ограничения»).
- Сравнение с объёмами сторонней CAD не проводилось; эталон — аналитика.
