## 2026-11-08 — Принят формат документа сборки и отмена/повтор

- JSON `bendcore-assembly` v2 (миграция v1): детали по пути и/или встроенный BRep с картой имён,
  внешние подсборки, сопряжения с индексом и сигнатурой, массивы, разнесённые виды,
  подавление; диагностика перемещённых/изменённых файлов по каждому сопряжению

  `reference_designator` (AP214/AP242, кириллица) — обозначение и наименование через STEP.
- `AssemblyHistory`: отмена/повтор всех изменений сборки, положения восстанавливаются побитно.
- Итог: 121/121, `check_no_stubs.sh` — 0 нарушений.

Открытые задачи: сопряжения внутри внешней подсборки (сейчас жёсткое тело); объединение
встроенных деталей без пути между документом и подсборкой.

- Демпфирование по метрике `diag(1, L²)` вместо масштаба Марквардта `diag(JᵀJ)`: второй не
  демпфирует почти свободные повороты, и на недоопределённых сборках LM не сходился за 200 итераций.
- Ранг (степени свободы) считается QR с выбором столбца, вклад сопряжений — последовательной
  ортогонализацией в порядке добавления. Избыточным считается только сопряжение без единого
  нового уравнения, частичное перекрытие (соосность + торец) — нет.
- От OCCT модуль не зависит: сущности задаются числами, связь с гранями OCCT — следующий шаг.

Следующий шаг: извлечение сущностей сопряжений из граней и рёбер `src/kernel/`, документ сборки
со ссылками на детали.
