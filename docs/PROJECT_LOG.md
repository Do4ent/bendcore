## 2026-11-06 — Фаза 0 запущена

Сделано:
- План `docs/ROADMAP_GENERAL_CAD.md` по результатам аудита исходников: твердотельное
  моделирование, решатель сборок, виды и экспорт чертежей — заглушки; работают эскиз
  (PlaneGCS), импорт STEP/IGES, CFD и тепловой решатель.
- Регламент `docs/PROJECT_PROCESS.md`: роли, правило «никаких заглушек», критерии готовности,
  владение файлами.
- Определения ролевых агентов в `.claude/agents/`.
- Точки подключения модулей `cmake/<модуль>.cmake` в корневом `CMakeLists.txt`
  (внутри `BENDCORE_WITH_OCCT`).

Решения:
- Новые подсистемы пишутся в новых каталогах (`src/kernel`, `src/modeling`,
  `src/assembly_v2`, `src/drawing_v2`), заглушки старых каталогов удаляются, а не
  дорабатываются.
- Ядро строится только в конфигурации с OCCT (`BENDCORE_WITH_OCCT=ON`).

Задачи фазы 0 в работе (параллельно):
1. Явный набор модулей OCCT вместо `file(GLOB libTK*.a)`; скрипт сборки OCCT для WASM.
2. `bendcore_kernel`: форма, сериализация BRep, тесселяция с привязкой к граням.
3. `bendcore_kernel_healing`: лечение геометрии, устойчивые булевы операции.
4. Удаление заглушек геометрии и экспорта чертежей.
5. `scripts/check_no_stubs.sh`, корпус STEP, регрессия импорта, CI.
