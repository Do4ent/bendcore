### QA: проверка заглушек, корпус STEP, регрессия импорта, CI (инженер качества)

Сделано: `scripts/check_no_stubs.sh` (полный режим + `--diff`, 15 правил, подавление
`qa-allow(<правило>): <причина>`), самотест `tests/qa/test_check_no_stubs.sh` на фикстурах;
генератор корпуса `tests/corpus/generate_corpus.cpp` (13 моделей, эталоны по формулам);
тест `test_step_corpus` (`cmake/qa.cmake`); workflow `.github/workflows/qa.yml`
(задачи `no-stubs` и `occt-native`); документация `docs/qa/QA.md`.

Решения:
- Движок правил на perl внутри `check_no_stubs.sh`: многострочные эвристики (пустое тело,
  возврат литерала, `success = true` без вычисления) нужны вне возможностей grep.
- Сгенерированный корпус закоммичен: регрессия на неизменных файлах + отдельный тест
  свежей генерации (цикл запись → чтение).
- Публичные модели NIST не загружены: прокси вернул 403 (см. `tests/corpus/README.md`).
- `STEPReader` не отдаёт имена деталей и цвета сборки — тест проверяет их через XCAF.
