# Журнал проекта bendcore CAD

Новые записи — сверху. Формат: дата, фаза, что сделано, решения, следующий шаг.

## 2026-11-07 — Фаза 4 (ранний старт): модель чертежа и экспорт

Сделано (`bendcore_drawing_v2`, `cmake/drawing.cmake`, документация `docs/drawing/`):
- 2D-модель листа: форматы ГОСТ 2.301 (основные и дополнительные) и ISO 216, слои, девять
  типов линий ГОСТ 2.303 с проверкой диапазонов, отрезок/дуга/окружность/полилиния/текст
  (ряд высот ГОСТ 2.304, наклон 75°)/штриховка (ГОСТ 2.306).
- Рамка и основная надпись ГОСТ 2.104 формы 1 и 2а, графы 19–23, подбор высоты и сжатия
  текста по метрикам шрифта.
- Писатели DXF R2000, SVG, PDF 1.4 со встроенным TrueType (CIDFontType2, ToUnicode).

Решения:
- DXF R2000 с `\U+XXXX` для не-ASCII (файл — чистый ASCII), а не R2007/UTF-8: меньше
  обязательных объектов, совместимость шире.
- PDF — свой писатель; шрифт DejaVu Sans / Liberation Sans берётся из системы и
  встраивается целиком (без subset и сжатия), шрифт ГОСТ тип Б не используется из-за лицензий.
- `src/dxf_reader.cpp` для проверки непригоден (возвращает фиксированные координаты) —
  тесты используют свой разбор групповых кодов и, по желанию, ezdxf.

Не сделано: сплайн, многострочный текст, форма 2, графы 24–26, subset шрифта.

## 2026-11-06 — Фаза 0 запущена

Сделано:
- План `docs/ROADMAP_GENERAL_CAD.md` по результатам аудита исходников: твердотельное
  моделирование, решатель сборок, виды и экспорт чертежей — заглушки; работают эскиз
  (PlaneGCS), импорт STEP/IGES, CFD и тепловой решатель.
- Регламент `docs/PROJECT_PROCESS.md`: роли, правило «никаких заглушек», критерии готовности,
  владение файлами.
- Определения ролевых агентов в `.claude/agents/`.
- Точки подключения модулей `cmake/<модуль>.cmake` в корневом `CMakeLists.txt`
  (внутри `BENDCORE_WITH_OCCT`).

Решения:
- Новые подсистемы пишутся в новых каталогах (`src/kernel`, `src/modeling`,
  `src/assembly_v2`, `src/drawing_v2`), заглушки старых каталогов удаляются, а не
  дорабатываются.
- Ядро строится только в конфигурации с OCCT (`BENDCORE_WITH_OCCT=ON`).

Задачи фазы 0 в работе (параллельно):
1. Явный набор модулей OCCT вместо `file(GLOB libTK*.a)`; скрипт сборки OCCT для WASM.
2. `bendcore_kernel`: форма, сериализация BRep, тесселяция с привязкой к граням.
3. `bendcore_kernel_healing`: лечение геометрии, устойчивые булевы операции.
4. Удаление заглушек геометрии и экспорта чертежей.
5. `scripts/check_no_stubs.sh`, корпус STEP, регрессия импорта, CI.
