# Production Deployment Checklist

## Pre-Deployment (20 items)

- [x] Code review completed
- [x] All tests passing (> 90% coverage)
- [x] Performance benchmarks met
- [x] Security audit passed
- [x] Database migration tested
- [x] Backup procedures tested
- [x] Rollback plan documented
- [x] Disaster recovery tested
- [x] Support team trained
- [x] Documentation complete
- [x] Configuration management updated
- [x] SSL certificates renewed
- [x] Load balancer configured
- [x] Monitoring/alerting enabled
- [x] CI/CD pipeline green
- [x] Stakeholder approval obtained
- [x] Customer communication sent
- [x] Change management approved
- [x] Infrastructure capacity verified
- [x] Communication plan tested

## Deployment Steps

- [ ] Pre-flight system checks
- [ ] Verify all services online
- [ ] Start database migration
- [ ] Monitor migration progress
- [ ] Deploy to green environment
- [ ] Run smoke tests on green
- [ ] Verify all endpoints
- [ ] Switch 10% traffic to green
- [ ] Monitor error rates (5 min)
- [ ] Switch 50% traffic to green
- [ ] Monitor performance (5 min)
- [ ] Switch 100% traffic to green
- [ ] Enable full monitoring
- [ ] Verify production metrics
- [ ] Send deployment notification

## Post-Deployment (24 hours)

- [ ] Monitor error rates
- [ ] Check application metrics
- [ ] Verify database integrity
- [ ] Monitor system performance
- [ ] Review user feedback
- [ ] Check support tickets
- [ ] Verify backup completion
- [ ] Document deployment notes
