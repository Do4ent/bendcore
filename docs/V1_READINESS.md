# Готовность bendcore к v1.0

Дата: 2026-11-13, ревизия `ccr-d188a25e-rml7z8` после записи журнала «Приняты операции фазы 2 и
доводка интерфейса». Владелец: технический писатель. Основание — `docs/ROADMAP_GENERAL_CAD.md`:
критерий готовности v1.0, минимальный функционал (раздел 2) и критерии «готово» фаз 0–5
(раздел 4).

## 1. Как оценивалось

| Статус | Значение |
|---|---|
| **выполнено** | реализовано на OCCT и проверено автоматическим тестом против независимого эталона; для функций интерфейса — есть в интерфейсе и покрыто сквозным тестом или тестом логики |
| **частично** | реализовано не полностью, только в библиотеке ядра без интерфейса, или проверено только против собственных данных (таблиц, писателя, экспорта bendcore) |
| **нет** | не реализовано |
| **требует человека** | автоматически не проверяется: нужен специалист, официальное издание стандарта, сторонняя программа или внешняя инфраструктура |

Правила строгости:

- Результаты тестов — по записям приёмки в `docs/PROJECT_LOG.md` (последняя: native 125/125,
  нагрузка и fuzz 11/11, WASM node 5/5, Jest 22/22, Playwright 16/16 наборов-сценариев,
  `check_no_stubs.sh` — 0 нарушений). Это локальные прогоны в среде разработки; на GitHub
  Actions они не подтверждены (раздел 4).
- Значение, взятое из таблицы, записанной по памяти, засчитывается только как «частично»:
  тесты сверяют геометрию с той же таблицей и ошибку в ней не поймают
  (`docs/STANDARDS_VERIFICATION.md`).
- Устаревшие отчёты о «завершении» не использовались (`docs/DOCS_CLEANUP.md`).
- «Ядро» — библиотеки C++ (`src/kernel`, `src/modeling`, `src/assembly_v2`, `src/drawing_v2`);
  «интерфейс» — страницы `web/*` поверх WASM-модулей (`README.md`).
