# Данные из стандартов, требующие сверки

У агентов разработки нет доступа к официальным изданиям ГОСТ/ISO (прокси закрывает
справочные сайты), поэтому часть табличных данных записана по памяти. Каждое значение
ниже помечено в коде и документации модуля; тесты сверяют геометрию с этими же таблицами
и ошибку в самой таблице не поймают.

Порядок сверки: инженер сравнивает таблицу с официальным изданием, исправляет значения,
меняет отметку на «сверено (издание, год)» и удаляет строку из этого списка.

| Стандарт | Что сверить | Где в коде | Документ |
|---|---|---|---|
| ГОСТ 2.104 | Размеры граф основной надписи форм 1 и 2а, число строк изменений | `src/drawing_v2/title_block*.cpp` | `docs/drawing/DRAWING_MODEL.md` |
| ГОСТ 2.305 | Размеры стрелок и букв обозначения разрезов/видов | `src/drawing_v2/views/` | `docs/drawing/VIEWS.md` |
| ГОСТ 7798 / ISO 4014, 4017 | Размеры болтов (s, k, e, b) М6–М24 | `src/assembly_v2/fasteners/tables.cpp` | `docs/assembly/FASTENERS.md` |
| ГОСТ 11738 / ISO 4762 | Размеры винтов; совпадение ГОСТ с ISO | там же | там же |
| ГОСТ 5915 / ISO 4032 | Размеры гаек (s, m, e) | там же | там же |
| ГОСТ 11371 / ISO 7089 | Размеры плоских шайб | там же | там же |
| ГОСТ 6402 | Размеры пружинных шайб М5–М12 | там же | там же |
| ГОСТ 3128 / ISO 2338 | Размеры штифтов; совпадение ГОСТ с ISO | там же | там же |

Дополняется по мере появления новых таблиц (допуски ISO 286, шероховатость, спецификация).
